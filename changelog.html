변경 사항

ShouArchive 버전별 업데이트 기록

1.1.3 — 2026년 11월 10일

추가

  • 프로파일 내보내기 — 「프로파일 관리」 에서 프로파일을 내보낼 수 있습니다. 하나는 프로파일 파일 그대로, 여러 개는 zip 파일 하나로 묶어 저장합니다. 프로파일마다 있는 「내보내기…」 버튼, 여러 개를 고른 뒤 목록 위 내보내기 버튼이나 오른쪽 클릭으로 내보냅니다
  • 팀별 보기 · 내보내기 — 팀이 둘 이상일 때 「팀」 에서 「전체」 를 고르면 목록이 팀마다 나뉘어 보이고, 팀마다 그 팀의 프로파일을 zip 으로 내보낼 수 있습니다. 여러 팀을 한꺼번에 내보내면 zip 안이 팀마다 폴더로 나뉩니다. 팀 · 전체 내보내기는 목록에 보이는 프로파일(상태 · 종류 · 검색으로 거른 그대로)만 담습니다

1.1.2 — 2026년 11월 5일

추가

  • 새 버전 알림 — 새 버전이 나오면 메인 창 오른쪽 아래 모서리에 「새 버전이 나왔습니다. v1.1.3」 처럼 한 줄로 알려 줍니다. 누르면 소식 › ShouArchive 에서 바뀐 점을 보고 「업데이트」 할 수 있습니다

고친 점

  • 산출물 검사 — 앱 언어가 简体中文 · 繁體中文 · Español 일 때 Android 결과의 「빌드 · 구성」 을 열면 앱이 꺼지던 문제를 고쳤습니다
  • 산출물 검사 — Android 「검사 기록」 에도 패키지명 · versionCode 가 남습니다

1.1.1 — 2026년 11월 4일

추가

  • 산출물 검사 — 「검사 기록」 을 새로 두었습니다. 검사한 설치 파일(파일 · 앱 이름 · 버전 · 결과, iOS 는 번들 ID · 서명까지)이 쌓이고 줄마다 메모를 남길 수 있습니다. 「만든 파일 열기」 왼쪽 버튼으로 엽니다
  • 앱 빌드 — iOS 빌드에 쓴 Swift 컴파일 설정(SWIFT_ACTIVE_COMPILATION_CONDITIONS · OTHER_SWIFT_FLAGS · 최적화 수준 등)을 히스토리에 남깁니다. 그 IPA 를 산출물 검사로 열면 「구성」 에서 보여 줍니다 (이 값은 IPA 안에 남지 않아, ShouArchive 로 빌드한 IPA 에만 보입니다)

바뀐 점

  • Android — 아래 메뉴에서 산출물 검사를 iOS 처럼 「빌드」 안으로 옮겼습니다

1.1.0 — 2026년 11월 3일

추가

  • AI 연동 — Claude Code · Claude 데스크톱 · Cursor · Codex 처럼 MCP 를 지원하는 AI 도구에 ShouArchive 를 연결하면, 이 Mac 의 프로파일 · 산출물 검사 결과 · App Store Connect 진행 상황을 말로 물어볼 수 있습니다. 왼쪽 위 「AI」 화면이나 설정 › AI 연동 에서 「AI 도구 연결 허용」 을 켭니다(기본 꺼짐)
  • AI 화면 — 메인 창 왼쪽 위 「AI」 에 AI 연동을 한 화면으로 모았습니다. 「AI 도구에 설치」 에서 「설치」 를 누르면 Claude Code · Claude 데스크톱 · Codex · Cursor · Gemini CLI · VS Code · Windsurf 의 설정에 ShouArchive 를 넣습니다(바꾸기 전 원래 파일은 백업). 켜기 스위치 · 도구마다 승인 방식 · 최근 실행 요청도 여기서 봅니다
  • AI 연동 — 프로파일 다시 만들기, App Store 문구 · 스크린샷 · 빌드 연결 · 심사 제출, Google Play 문구 · 이미지 · 트랙 출시 같은 실행 요청은 「실행 요청 허용」 을 켠 뒤 요청마다 ShouArchive 승인 창에서 승인한 것만 실행하고 기록에 남깁니다. 도구마다 「승인 후 실행」 · 「승인 없이 실행」 · 「쓰지 않음」 을 고를 수 있습니다
  • AI 연동 — 「지금 연결」 에서 연결된 AI 도구와 승인을 기다리는 요청을 봅니다. App Store Connect · Google Play 키는 이 Mac 에 그대로 있고, AI 도구에는 도구가 부른 기능의 결과만 건넵니다
  • 메뉴 막대 — 메뉴 막대 아이콘 옆에 승인 대기 · 빌드 단계 · 7일 안에 만료되는 프로파일(D-N)이 보이고, 패널에서 빌드 진행 · 30일 안에 만료되는 프로파일 · 최근 OTA 링크 복사 · AI 연동 상태를 봅니다. 설정 › 일반 에서 끌 수 있습니다
  • 설정 — 설정에 「출처」 탭을 새로 두었습니다. Android 로봇 그림의 출처와 앱에 들어간 오픈소스(Sparkle · Lottie)의 라이선스 전문을 볼 수 있습니다

바뀐 점

  • 업데이트 — 「자동으로 업데이트 확인」 이 켜져 있으면 앱을 켤 때도 한 번 확인합니다 (예전에는 마지막 확인 뒤 하루가 지나야 확인했습니다)

1.0.7 — 2026년 11월 1일

고친 점

  • 앱 빌드 — 도구 없음 안내에서 「App Store 로 이동」 · 「다운로드 페이지로 이동」 · 「Android Studio 열기」 를 누르면, 받는 곳을 연 뒤 「닫기」 처럼 이전 화면으로 돌아갑니다

1.0.6 — 2026년 10월 31일

추가

  • 앱 빌드 — Xcode 가 없으면 iOS 앱 빌드 화면에 들어올 때 창 가운데에 안내가 뜹니다. 「App Store 로 이동」 은 App Store 의 Xcode 페이지를 열고, 「닫기」 는 이전 화면으로 돌아갑니다
  • 앱 빌드 — Android SDK 나 JDK 가 없을 때도 같은 안내가 뜹니다. 「다운로드 페이지로 이동」 은 Android Studio 다운로드 페이지를 열고, Android Studio 가 이미 설치돼 있으면 「Android Studio 열기」 로 바뀝니다
  • 앱 빌드 — 빌드 화면 위 안내와 실패한 작업에도 「App Store 에서 Xcode 받기」 · 「Android Studio 받기」 단추가 생겼습니다. 설치하고 ShouArchive 로 돌아오면 안내가 사라집니다

바뀐 점

  • API 키 — 「백업 내보내기」 로 저장하면 Finder 에서 저장한 파일을 골라 보여 줍니다

고친 점

  • 앱 빌드 — Xcode 가 없을 때 iOS 빌드 · 업로드 · 기기 설치 등에서 Apple 의 영어 오류가 그대로 보이던 것을 「이 작업에는 Xcode 가 필요합니다」 안내로 바꿨습니다. macOS 의 개발자 도구 설치 창도 더 이상 뜨지 않습니다
  • 앱 빌드 — Xcode 가 설치돼 있어도 xcode-select 가 Command Line Tools 를 가리키면 iOS 작업이 실패하던 것을 고쳤습니다. 이제 설치된 Xcode 를 찾아 씁니다

1.0.5 — 2026년 10월 31일

바뀐 점

  • API 키 — iOS 키의 .p8 내용을 macOS 키체인에 보관합니다. 원본 .p8 파일을 지우거나 옮겨도 계속 쓸 수 있고, 이미 등록한 키도 원본이 남아 있으면 앱을 켤 때 키체인에 넣습니다
  • API 키 — iOS 키에도 「백업 내보내기」 가 생겼습니다. 키체인에 보관한 .p8 을 AuthKey_<Key ID>.p8 파일로 저장합니다
  • 라이선스 — 이 Mac 에서 쓰고 있는 키의 링크를 열면 「이미 이 Mac 에 등록된 라이선스입니다」 안내만 보입니다
  • 라이선스 — 다른 라이선스의 키로 바꾸면 예전 라이선스에서 이 Mac 의 자리를 돌려줍니다
  • 라이선스 — 철회된 라이선스는 설정 › 라이선스에서 구매 전처럼 보입니다(상태 · 이유 · 키만 남음)

고친 점

  • 라이선스 — 링크로 키를 등록하다 실패하면 오류가 경고와 함께 두 번 보이던 것을 한 곳에만 보이게 했습니다
  • API 키 — 「백업 내보내기」 가 새 폴더를 만들지 않아 파일을 저장하지 못하던 것을 고쳤습니다
  • 확인 창 — 일부 확인 창(키 백업 · 키 삭제 · 비공개 테스트 트랙 만들기)에 「취소」 단추가 두 개 보이던 것을 고쳤습니다

1.0.4 — 2026년 10월 30일

고친 점

  • 창 크기 — 아래 탭 바 · 하위 메뉴로 화면을 옮길 때 창이 저절로 세로로 길어지면, 바로 전 높이로 되돌립니다
  • macOS 26 — 툴바에 바탕을 깔아, 창 제목이 왼쪽 칸 경계선에 걸쳐 보이지 않습니다
  • 프로파일 — 영어 화면에서 인증서 만료일 앞의 띄어쓰기가 빠지던 것을 고쳤습니다

1.0.3 — 2026년 10월 29일

바뀐 점

  • 소식 — 왼쪽 위 iOS / Android 옆 「소식」 으로 옮겼습니다(아래 탭 바에서 빠짐). 안에서 iOS · Android · ShouArchive 를 고릅니다
  • 업데이트 내역 — 소식 › ShouArchive 에 버전마다 바뀐 점을 보여 줍니다. 새 버전이 있으면 「새 버전」 과 「업데이트 확인…」

1.0.2 — 2026년 10월 29일

바뀐 점

  • 소식 — 「원문 보기」 가 앱 언어로 번역된 원문을 엽니다(번역이 없으면 영어 원문)
  • API 키 — 키를 저장 · 삭제한 결과를 화면 위쪽에 잠깐 알려 줍니다

1.0.1 — 2026년 10월 29일

추가

  • 소식 — Apple · Google 의 심사 · 정책 소식을 모은 새 탭 (아래 탭 바 맨 끝, 읽지 않은 소식 배지). 설정 › 일반에서 자동으로 받기를 끌 수 있습니다

1.0.0 — 첫 출시

기능

  • 프로파일 관리 — 설치된 프로파일 · 만료 배지 · 필터 · 두 개 비교
  • 프로파일 다운로드 · 생성 · 갱신 · 기기 등록 (App Store Connect API 키)
  • 산출물 검사 — IPA · APK · AAB, 서명 · 권한 · 보안 설정
  • 히스토리 — 프로파일 · 빌드 · 배포 작업 기록
  • 앱 빌드 · 작업 대기열 — IPA · APK 를 직접 빌드, 여러 작업을 줄 세워 실행
  • 앱 업로드 — TestFlight · Play Console 로 올리기
  • 기기 설치 — 기기 목록 · 설치 · 재설치
  • 다시 서명 · 라이브러리 · IPA 정리 — 다른 프로파일로 다시 서명, 산출물 보관, IPA 정리
  • OTA 배포 — 배포용 설치 파일 만들기
  • 스토어 배포 (iOS · Android) — 스토어 정보 · 스크린샷 · 심사 제출 · 리뷰 답글
