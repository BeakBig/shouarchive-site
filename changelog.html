1.0.2 — 2026년 10월 29일

바뀐 점

  • 소식 — 「원문 보기」 가 앱 언어로 번역된 원문을 엽니다(번역이 없으면 영어 원문)

1.0.1 — 2026년 10월 29일

추가

  • 소식 — Apple · Google 의 심사 · 정책 소식을 모은 새 탭 (아래 탭 바 맨 끝, 읽지 않은 소식 배지). 설정 › 일반에서 자동으로 받기를 끌 수 있습니다

1.0.0 — 첫 출시

기능

  • 프로파일 관리 — 설치된 프로파일 · 만료 배지 · 필터 · 두 개 비교
  • 프로파일 다운로드 · 생성 · 갱신 · 기기 등록 (App Store Connect API 키)
  • 산출물 검사 — IPA · APK · AAB, 서명 · 권한 · 보안 설정
  • 히스토리 — 프로파일 · 빌드 · 배포 작업 기록
  • 앱 빌드 · 작업 대기열 — IPA · APK 를 직접 빌드, 여러 작업을 줄 세워 실행
  • 앱 업로드 — TestFlight · Play Console 로 올리기
  • 기기 설치 — 기기 목록 · 설치 · 재설치
  • 다시 서명 · 라이브러리 · IPA 정리 — 다른 프로파일로 다시 서명, 산출물 보관, IPA 정리
  • OTA 배포 — 배포용 설치 파일 만들기
  • 스토어 배포 (iOS · Android) — 스토어 정보 · 스크린샷 · 심사 제출 · 리뷰 답글
