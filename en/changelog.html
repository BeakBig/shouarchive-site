Changelog

ShouArchive release history, version by version

1.2.2 — November 13, 2026

New

  • Filter provisioning by certificate — In Manage Profiles, click a keychain certificate in the “Certificate” card to see only the provisioning profiles that contain it. Click it again to see all
  • Required screenshot sizes — The “Size” list in Store › App Store › Screenshots marks the sizes you must have to submit to the App Store as “Required” (iPhone 6.3″, iPad 13″ if your app supports iPad, Mac and more, per Apple’s “Screenshot specifications”)

Changes

  • History — Build records are stacked on the left with the newest on top, and your plans are shown large on the right. Click a build to open its details at the top right (all themes)
  • Automatic updates — When the automatic check finds a new version, the update window now appears right away, even while you’re using the app
  • App Store failure messages — When something fails, ShouArchive now tells you what to do instead of showing error codes and Apple’s raw messages

Fixes

  • ShouArchive dark theme — Selected buttons, such as in “New Workflow…” › “Start with”, showed white text on a white background
  • Translations — In English and Spanish the number of profiles expiring soon was reversed (“10 of 1”), and some messages, such as Clean Up completion messages in English, Spanish and Chinese, could mix up their values

1.2.1 — November 13, 2026

Fixes

  • Misleading wording — In Store › Google Play › App setup, the messages shown while reading or saving the developer contact details, “Reading contact details…” and “Saving contact details…”, now say “Reading the information saved in the store…” and “Saving the information to the store…”. They could look as if ShouArchive was reading your Mac’s contacts. ShouArchive doesn’t read your Mac’s contacts

1.2.0 — November 13, 2026

New

  • New “Poster” theme — Move between screens with the numbered section bar, and see what needs attention at a glance on the first screen, Today. Press ⌘K (“Where to?”) to jump straight to any screen. If you’ve never picked a theme, the app opens in Poster; you can switch themes from the theme menu at the top right of the window
  • Workflows — Chain project, compile, signing, install file, inspection and upload as nodes and run them in one go. Add several signing branches to build Development, Ad Hoc and App Store together. The App Build tab has been replaced by Workflows. Uploading to the Google Play production track always asks for confirmation before running
  • Direct distribution for Mac apps — With the signing method “Direct Distribution (Mac)” in a workflow, ShouArchive signs with Developer ID, notarizes and builds a DMG
  • Automatic profile creation — If you have an App Store Connect API key and no matching profile, one is created and installed during the build. You can also create it ahead of time with “Create Profile…” in the signing field. Only certificates already on this Mac are used; no new certificates or App IDs are created
  • Dashboard — Things to know, workflows, schedule, iOS, Android and news on one screen
  • History › Timeline · Plans — Keep dev notes, plan a workflow to run on a set day, and get warned about overlapping schedules. You can export them as a calendar file (.ics)
  • Build progress at the notch — While a build runs, the app name and current step appear at the top center of the screen (Settings › General “Show build progress at the notch”)
  • Concurrent builds — The build queue runs 2–3 builds at once across iOS and Android
  • Monthly subscription — You can activate a monthly subscription key (US$3/month · 4 Macs). See its status and next payment date in Settings › License, and cancel or change your payment method with “Manage Billing…”. Until December 31, 2026 you can subscribe early from Pricing (first 3 payments US$2, next payment on February 1, 2027)
  • Buy another license — To use more Macs, buy a new key with “Buy Another License…” in Settings › License
  • New App Store screenshot system — Screenshots are read, uploaded, reordered and deleted through App Store Connect’s new screenshot system (App Asset Library), including the iPhone Duo size
  • Google Play — Mark images as “AI-generated image”, and see each track’s review and publishing stage
  • Connection check — Screens that need the internet show “Network Disconnected” when the connection drops and reload when it comes back. Uploads now fail right away instead of waiting a long time
  • Usage counts — Once a day the app sends anonymous usage counts (whether it was opened that day, and how often each screen and feature was used) (Privacy Policy, section 5)

Changes

  • Manage Profiles — Export and the per-team view now fit the new layout, and when several packages are selected you export or delete them from a single bar above the list
  • First release — Apps with no released version are no longer asked for “What’s New in This Version”
  • Clean Up — Also removes system data left behind by builds

Fixes

  • Typing speed — Fixed typing slowing down with every character, for example when entering store information
  • Cancelling builds — Fixed a cancelled build not stopping right away
  • Translations — Fixed some text appearing in Korean in other languages

1.1.4 — November 10, 2026

Fixes

  • Manage Profiles speed — With many profiles, “Manage Profiles” no longer pauses briefly each time you select in the list or export (introduced in 1.1.3)

1.1.3 — November 10, 2026

New

  • Export profiles — You can now export profiles from “Manage Profiles”. A single profile is saved as the profile file itself; several are bundled into one zip file. Use the “Export…” button on each profile, or select several and use the export button above the list or the right-click menu
  • View and export by team — When you have more than one team, choosing “All” under “Team” splits the list by team, and each team’s profiles can be exported as a zip. Exporting several teams at once puts each team in its own folder inside the zip. Team and “All” exports include only the profiles shown in the list (as filtered by status, type and search)

1.1.2 — November 5, 2026

New

  • New version notice — When a new version is out, a one-line notice such as “A new version is available. v1.1.3” appears in the bottom-right corner of the main window. Click it to see what changed in News › ShouArchive and choose “Update”

Fixes

  • Artifact Inspection — Fixed the app quitting when opening “Build · Configuration” in an Android result while the app language was 简体中文, 繁體中文 or Español
  • Artifact Inspection — Android entries in “Inspection History” now keep the package name and versionCode too

1.1.1 — November 4, 2026

New

  • Artifact Inspection — New “Inspection History”: the install files you inspect (file, app name, version and result; bundle ID and signing too for iOS) are listed, and you can add a note to each. Open it with the button to the left of “Open Built File”
  • App Build — The Swift compile settings used for an iOS build (SWIFT_ACTIVE_COMPILATION_CONDITIONS, OTHER_SWIFT_FLAGS, optimization level and more) are saved in History. Open that IPA in Artifact Inspection to see them under “Configuration” (these values aren’t stored inside an IPA, so only IPAs built with ShouArchive show them)

Changes

  • Android — In the bottom menu, Artifact Inspection now sits inside “Build”, as on iOS

1.1.0 — November 3, 2026

New

  • AI Integration — Connect ShouArchive to an AI tool that supports MCP, such as Claude Code, Claude Desktop, Cursor or Codex, and you can ask in plain language about the profiles on this Mac, artifact inspection results and App Store Connect progress. In the top-left “AI” screen or Settings › AI Integration, turn on “Allow AI tools to connect” (off by default)
  • AI Screen — The “AI” at the top left of the main window gathers AI Integration on one screen. Under “Install in AI tool”, press “Install” to add ShouArchive to the settings of Claude Code, Claude Desktop, Codex, Cursor, Gemini CLI, VS Code and Windsurf (the original file is backed up before it is changed). The on switch, the approval mode for each tool and recent action requests are also shown here
  • AI Integration — Action requests such as re-creating profiles, App Store text, screenshots, build attachment and review submission, and Google Play text, images and track releases require “Allow action requests” to be turned on. After that, only what you approve for each request in the ShouArchive approval window is run, and it is kept in the history. For each tool you can choose “Run after approval”, “Run without approval” or “Don’t use”
  • AI Integration — “Connected Now” shows the AI tools that are connected and the requests waiting for approval. Your App Store Connect and Google Play keys stay on this Mac, and the AI tool receives only the result of the feature it called
  • Menu Bar — Next to the menu bar icon you see pending approvals, the build step and profiles expiring within 7 days (D-N). The panel shows build progress and profiles expiring within 30 days, lets you copy the latest OTA link, and shows the AI Integration status. You can turn it off in Settings › General
  • Settings — A new “Acknowledgments” tab shows where the Android robot artwork comes from and the full licenses of the open-source software in the app (Sparkle, Lottie)

Changes

  • Updates — When “Check for Updates Automatically” is on, the app now also checks once when it launches (previously it waited until a day had passed since the last check)

1.0.7 — November 1, 2026

Fixes

  • App Build — In the missing-tools notice, “Go to the App Store”, “Go to the Download Page” and “Open Android Studio” now open where to get the tool and then take you back to the previous screen, just like “Close”

1.0.6 — October 31, 2026

New

  • App Build — If Xcode isn’t installed, a notice now appears in the middle of the window when you open the iOS App Build screen. “Go to the App Store” opens Xcode’s App Store page, and “Close” takes you back to the previous screen
  • App Build — The same notice appears when the Android SDK or JDK is missing. “Go to the Download Page” opens the Android Studio download page; if Android Studio is already installed, the button becomes “Open Android Studio”
  • App Build — The notice at the top of the build screen and failed jobs now also have “Get Xcode from the App Store” / “Get Android Studio” buttons. The notice goes away once you install the tool and come back to ShouArchive

Changes

  • API Key — Saving with “Export backup” now shows the saved file selected in Finder

Fixes

  • App Build — Without Xcode, iOS builds, uploads, device installs and similar tasks showed Apple’s raw English error; they now say “This needs Xcode” and what to do next. The macOS prompt to install developer tools no longer appears
  • App Build — Fixed iOS tasks failing when Xcode is installed but xcode-select points to the Command Line Tools; ShouArchive now finds and uses the installed Xcode

1.0.5 — October 31, 2026

Changes

  • API Key — iOS keys now keep the .p8 contents in the macOS keychain. You can delete or move the original .p8 file and keep using the key; keys you already added move to the keychain at launch while the original file is still there
  • API Key — iOS keys now have “Export backup”, which saves the .p8 kept in the keychain as an AuthKey_<Key ID>.p8 file
  • License — opening the link for the key this Mac already uses now just says “This license is already registered on this Mac”
  • License — switching to a key for a different license releases this Mac’s seat on the previous license
  • License — a revoked license now looks like before purchase in Settings › License (only the status, reason, and key remain)

Fixes

  • License — when registering a key from a link fails, the error now appears in one place instead of twice next to the warning
  • API Key — fixed “Export backup” failing to save because it didn’t create the new folder
  • Confirmation dialogs — fixed two “Cancel” buttons in some dialogs (key backup, key deletion, creating a closed testing track)

1.0.4 — October 30, 2026

Fixes

  • Window size — if the window grows taller on its own when you switch screens with the bottom tab bar or a sub-menu, it goes back to its previous height
  • macOS 26 — the toolbar now has a background, so the window title no longer sits across the left column’s divider
  • Profiles — fixed the missing space before certificate expiry dates in English

1.0.3 — October 29, 2026

Changes

  • News — moved to the top-left switcher next to iOS / Android (no longer in the bottom tab bar). Inside, choose iOS, Android or ShouArchive
  • Release notes — News › ShouArchive shows what changed in each version. When a newer version is out, you’ll see New Version and Check for Updates…

1.0.2 — October 29, 2026

Changes

  • News — View original opens the original in the app’s language when a translation exists (otherwise in English)
  • API Key — the result of saving or deleting a key appears briefly at the top of the screen

1.0.1 — October 29, 2026

New

  • News — a new tab with App Review and policy news from Apple and Google (at the end of the bottom tab bar, with an unread badge). You can turn off automatic fetching in Settings › General

1.0.0 — First release

Features

  • Profile management — installed profiles · expiry badges · filters · side-by-side comparison
  • Download, create and renew profiles · register devices (App Store Connect API key)
  • File inspection — IPA · APK · AAB, signing · permissions · security settings
  • History — a record of profile, build and release jobs
  • App build · job queue — build IPAs and APKs yourself, queue several jobs to run in turn
  • App upload — upload to TestFlight and Play Console
  • Device install — device list · install · reinstall
  • Re-signing · library · IPA cleanup — re-sign with another profile, keep your artifacts, clean up IPAs
  • OTA distribution — create install files for distribution
  • Store release (iOS · Android) — store listing · screenshots · submission for review · review replies
