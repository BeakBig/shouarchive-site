Changelog

ShouArchive release history, version by version

1.0.4 — October 30, 2026

Fixes

  • Window size — if the window grows taller on its own when you switch screens with the bottom tab bar or a sub-menu, it goes back to its previous height
  • macOS 26 — the toolbar now has a background, so the window title no longer sits across the left column’s divider
  • Profiles — fixed the missing space before certificate expiry dates in English

1.0.3 — October 29, 2026

Changes

  • News — moved to the top-left switcher next to iOS / Android (no longer in the bottom tab bar). Inside, choose iOS, Android or ShouArchive
  • Release notes — News › ShouArchive shows what changed in each version. When a newer version is out, you’ll see New Version and Check for Updates…

1.0.2 — October 29, 2026

Changes

  • News — View original opens the original in the app’s language when a translation exists (otherwise in English)
  • API Key — the result of saving or deleting a key appears briefly at the top of the screen

1.0.1 — October 29, 2026

New

  • News — a new tab with App Review and policy news from Apple and Google (at the end of the bottom tab bar, with an unread badge). You can turn off automatic fetching in Settings › General

1.0.0 — First release

Features

  • Profile management — installed profiles · expiry badges · filters · side-by-side comparison
  • Download, create and renew profiles · register devices (App Store Connect API key)
  • File inspection — IPA · APK · AAB, signing · permissions · security settings
  • History — a record of profile, build and release jobs
  • App build · job queue — build IPAs and APKs yourself, queue several jobs to run in turn
  • App upload — upload to TestFlight and Play Console
  • Device install — device list · install · reinstall
  • Re-signing · library · IPA cleanup — re-sign with another profile, keep your artifacts, clean up IPAs
  • OTA distribution — create install files for distribution
  • Store release (iOS · Android) — store listing · screenshots · submission for review · review replies
