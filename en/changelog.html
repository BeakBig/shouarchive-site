Features

  • Profile management — installed profiles · expiry badges · filters · side-by-side comparison
  • Download, create and renew profiles · register devices (App Store Connect API key)
  • File inspection — IPA · APK · AAB, signing · permissions · security settings
  • History — a record of profile, build and release jobs
  • App build · job queue — build IPAs and APKs yourself, queue several jobs to run in turn
  • App upload — upload to TestFlight and Play Console
  • Device install — device list · install · reinstall
  • Re-signing · library · IPA cleanup — re-sign with another profile, keep your artifacts, clean up IPAs
  • OTA distribution — create install files for distribution
  • Store release (iOS · Android) — store listing · screenshots · submission for review · review replies
