Download questions

Can I download a file and install it myself?

The Mac App Store edition is a sandboxed app, so it can only be installed through the Mac App Store. There is no separate file to download. Only the commercial edition gives you a .dmg file to download from this page.

What if the downloaded file won't open?

The commercial edition's .dmg is released with a signature and notarization. If macOS still blocks it, let Support know — sending the macOS version and a screenshot of the error helps us look into it faster.

How do I check that the file is safe?

When the commercial edition launches, the checksum (SHA-256) of the .dmg will be posted on this page. After downloading, compare it with shasum -a 256 ShouArchive.dmg.
