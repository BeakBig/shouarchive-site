Getting started

Where are profiles read from?

The app reads the folder where Xcode keeps provisioning profiles directly. There is nothing to allow or set up.

  • ~/Library/Developer/Xcode/UserData/Provisioning Profiles — Xcode 16 and later
  • ~/Library/MobileDevice/Provisioning Profiles — older Xcode versions

A .mobileprovision file kept anywhere else can be dragged into the window or opened with "Add from file…".

Which file types are supported?
  • Artifact inspection: .ipa (iOS tab), .apk and .aab (Android tab)
  • Profiles: .mobileprovision
  • API key: the .p8 file downloaded from App Store Connect

Drop a file onto the window or use "Choose file…" (⌘O).

Profiles and the App Store Connect API

How do I create an App Store Connect API key?
  1. Go to App Store Connect › Users and Access › Integrations › App Store Connect API.
  2. Generate a Team key. Reading and creating profiles and devices usually requires the Admin role.
  3. Open the API Key tab in the menu at the bottom of the app (or Settings (⌘,) › API Key), click "New Key" and enter the Issuer ID, Key ID and the downloaded .p8 file. Picking an AuthKey_XXXXXXXX.p8 file fills in the Key ID, and the team is read from Apple when you save (if it can't be read, the app asks you to choose one). Spaces and line breaks picked up while pasting are removed automatically.

Apple lets you download the .p8 file only once, so keep it somewhere safe. The app never uses your Apple ID or two-factor codes.

Where is the API key stored, and where is it sent?

The .p8 file stays wherever you keep it; the app only remembers a reference to it (a security-scoped bookmark). Request tokens are signed on your Mac, and the key itself is never sent anywhere — the app talks only to Apple's App Store Connect API (api.appstoreconnect.apple.com). Removing a key in the app does not delete the .p8 file.

What do "Expiring soon" and the D-N badge mean?

A profile that expires within 30 days is "expiring soon" and shows the days left as an orange D-N badge. Anything past its date is "expired" (red). "New" means recently created; "Duplicates" flags two or more profiles with the same team, app ID and type.

What does the "Certificates" card show?

It shows the code-signing certificates in this Mac's keychain, including expired ones. The certificates embedded in each profile are shown in the detail and compare views, with SHA-1 and SHA-256 copy buttons.

How many devices can I register?

An Apple Developer account can register up to 100 devices per type (iPhone, iPad, Mac, …) per membership year. Devices you disable still take up a slot until the membership renews. The Device tab under Profile › Download Profile shows current usage per type (for example, iPhone 3 / 100).

Artifact inspection

Does inspecting a file change it or upload it?

No. The file is read only: the original is never modified, no result file is written next to it, and nothing is sent to any server. Results are shown in the app window only.

I don't know what an item means.

Item names with a dotted underline (permissions, device features, manifest settings, certificate fingerprints, entitlements and so on) open a popover with What it is · Details · Watch out. For the 16 KB card, click the ⓘ next to the title.

What does the 16 KB page-size check look at?

Starting with Android 15 some devices use 16 KB memory pages, and Google Play requires native libraries that support them. The app checks the ELF LOAD alignment of 64-bit (arm64-v8a, x86_64) .so files and, for uncompressed .so files stored in an APK, their 16 KB boundary inside the archive, and lists the libraries that don't comply.

OTA distribution

Does ShouArchive host my OTA install files?

No. In a <name>_OTA folder next to your IPA or APK, ShouArchive writes an install page (install.html), a manifest.plist and a QR code. It only creates these files; it does not host them or provide a download link. Upload the whole folder to an HTTPS server you run (your company web server, static hosting on a cloud storage service, and so on) so that it matches the IPA address you entered in the app. iOS only starts an install from an HTTPS address.

Pricing · License

How much is it, and what's included?

The first purchase is US$29 (plus tax) and includes the license and 1 year of updates. One license key works on 2 Macs. Profile management, API keys, artifact inspection, history, app build, job queue, app upload, device installation, re-signing, library, IPA cleanup, OTA distribution and store publishing are all included. What you can use during the trial, after the trial and after purchase is summarized in the table on the pricing page.

When is it coming out?

The price is set — US$29 for the first purchase (1 year of updates included), then US$15 a year for updates (plus tax). The release date is not set yet. As soon as it is, we will put it on the pricing page and the download page. If you have questions, write to support@shouarchive.beakbig.com.

How do I register my license key?

After payment, you get your key on the payment-complete page and by email. On the Mac where ShouArchive is installed, click “Open in ShouArchive” on that page or the “Register in the app” link in the email; the app asks whether to register this Mac — click “Register” and you’re done. If the link doesn’t open the app, go to Settings › License › Enter key… and enter the email you paid with and the key. If you paid from the app, you can just click “Check Automatically” on that Mac. Paying doesn’t register a Mac by itself, so if you bought it for another Mac, register it on that Mac.

I lost my license key

Enter the email address you paid with on Get your license key again, and we’ll send the same key to that address. You can also use Settings › License › Get Key Again… in the app. Keys are only sent to the address used for the purchase. If you mistyped your email at checkout, send the payment date and what appears on your card statement to support@shouarchive.beakbig.com.

I think someone else knows my license key

Enter the email you paid with on Change your license key and we’ll send you a confirmation link (you can also use Settings › License › Change key… in the app). When you open the link and click “Change key”, we send a new key to your purchase email; the old key stops working and all registered Macs are released. Register the Macs you keep using again with the new key. From the second Mac on, we email you whenever a new Mac is registered, so if it wasn’t you, you can change the key right away with the link in that email.

How do I move to another Mac?

On the Mac you use now, press “Deactivate” in Settings › License to free up the slot, then register the same key on the new Mac. If you can’t use the old Mac anymore, the new Mac shows the registered Macs (model, registration date, last used) when all slots are taken; deactivate the one you no longer use and this Mac is registered right away (you can deactivate other Macs up to 3 times in 30 days). One key can be used on up to 2 Macs at the same time.

Does the app stop working when my update period ends?

No. Once you buy it, it is yours to keep. Versions released during your update period keep working after the period ends. Only versions released after it ends require renewing updates (US$15 a year) before you can install them. Renewal is automatic (we notify you 7 days before by email and in the app) and you can turn it off at any time from the management link in Paddle's billing emails or under Settings › License › "Manage billing…"; if you renew again after the period has ended, a new year starts from that payment date.

What happens when the trial ends?

The 14-day trial starts without a payment method, so nothing is charged automatically when it ends. If the trial ends without a license key, you can keep using profile management (including download, creation and device registration), artifact inspection, API key management and history (viewing records only); app build, job queue, app upload, device installation, re-signing, library, IPA cleanup, OTA distribution and store publishing reopen once you buy and enter the key in Settings › License.

How do I get a refund?

Both the first purchase and update renewals are refunded in full within 14 days of payment. Send your payment email and order number (on the Paddle receipt) to support@shouarchive.beakbig.com and the seller requests the refund from Paddle right away — this is the fastest way. You can also ask Paddle directly through the link in the receipt email or at paddle.net. The app shows the same instructions under Settings › License › "How to cancel…". The full terms are in the Refund Policy.

I want my personal data erased

Enter your payment email on the Erase my data page and we send you a confirmation email. Clicking "Erase" in the link from that email revokes every license under that email, deactivates the registered Macs, and deletes the purchase email, keys and delivery records. This cannot be undone, and the key cannot be sent again. Payment records (transaction id, type, time) are kept for 5 years as required by law, and payment information held by Paddle must be requested from Paddle separately. Details are in Section 11 of the Privacy Policy.

General

How do I change the language?

Open the globe menu in the toolbar, pick a language and confirm "Restart now". The app relaunches in that language; your work is kept. Supported: English, 한국어, 日本語, 简体中文, 繁體中文 and Español.

Theme and text size?

Choose a color theme (Black & White · ShouArchive) and Light, Dark or System Settings from the theme menu in the toolbar. Text size goes from 85 % to 150 % via the View menu (Bigger ⌘+, Smaller ⌘-, Default ⌘0) or Settings (⌘,) › Display.

System requirements

macOS 15 Sequoia or later, on Apple Silicon or Intel Macs. An App Store Connect API key is needed for downloading and creating profiles and registering devices, and an internet connection is needed for license checks, update checks, app upload and store publishing. Artifact inspection and viewing installed profiles work offline.

How do I report a problem?

Email support@shouarchive.beakbig.com with the following and it can be looked at quickly:

Inside the app you can also write one directly from Help › "Send Feedback · Suggestions…" (or Settings (⌘,) › "Compose Email…"). The app version and macOS details are added below your message automatically.

  • macOS version (Apple menu › About This Mac)
  • App version (ShouArchive menu › About ShouArchive)
  • What you did, step by step, and what happened
  • A screenshot or the exact error text, if possible

You don't need to attach IPA, APK or profile files. If one is needed it will be requested separately — and before sending anything, make sure it contains no key files (.p8) or sensitive data.
