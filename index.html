프로파일 관리 · 산출물 검사 · OTA 배포 파일 — 배포 직전에 확인할 것들을 한 앱에서.

IPA · APK · AAB 를 열어 스토어에 보일 정보와 서명 · 권한을 바로 확인하고, 프로비저닝 프로파일을 만료일과 함께 관리하고, 테스트 배포용 OTA 설치 파일까지 만듭니다. 파일은 Mac 안에서만 읽습니다.

프로파일

프로비저닝 프로파일, 만료일부터 기기 등록까지

Xcode 가 설치한 프로파일을 한눈에 보고, App Store Connect API 키가 있으면 내려받기 · 만들기 · 갱신까지 앱 안에서 끝냅니다.

설치된 프로파일

  • 목록마다 D-N 만료 배지 — 30일 안에 만료되는 것은 주황, 만료된 것은 빨강
  • 필터: 전체 · 신규 · 중복 / 유효 · 곧 만료 · 만료
  • 상세: 기기 UDID · 들어 있는 인증서(SHA-1 · SHA-256) · Entitlements, 항목별 복사
  • 두 프로파일을 나란히 비교 — 기기 · 인증서 · Entitlements 차이
  • .mobileprovision 을 끌어다 놓아 추가, 여러 개 골라 삭제

App Store Connect API

  • 팀의 프로파일 목록을 받아 없는 것만 골라 설치
  • 등록된 기기 목록과 새 기기 등록 — 종류별 한도 표시 (예: iPhone 3 / 100)
  • 새 프로파일 만들기: 종류 · 플랫폼 · 번들 ID · 인증서 · 기기
  • 기기가 바뀌었거나 만료가 가까우면 다시 만들기 · 갱신

Issuer ID · Key ID · .p8 만 씁니다. 키 파일은 Mac 에 그대로 두고, 요청 토큰은 로컬에서 서명합니다.

기록

  • 다운로드 · 생성 · 다시 만들기 · 기기 등록 · 추가 · 삭제를 날짜별로
  • 이름 · 번들 ID · UUID · UDID 로 검색
  • 누가 언제 어떤 프로파일을 바꿨는지 되짚을 때

산출물 검사

IPA · APK · AAB, 올리기 전에 열어 보기

파일을 끌어다 놓으면 외부 도구 없이 바로 분석합니다. 스토어에 보일 정보부터 서명 · 권한 · 보안 설정까지, 항목마다 설명이 붙어 있어 처음 보는 값도 그 자리에서 이해할 수 있습니다.

스토어 표시 정보

제품 페이지에 보일 값 중 산출물에서 읽을 수 있는 것을 미리 보여 줍니다.

  • 아이콘 · 이름 · 제공자 · 크기 · 지원 언어
  • iOS: 카테고리 · 호환성 · ATT(추적 허용 요청) 여부 · 개인정보 매니페스트 요약
  • Android: 다운로드 크기 · 필요한 Android 버전 · 권한 수 · 인앱 결제 · 광고 ID · 지원 기기

iOS 서명 · 권한

  • 서명 · 프로비저닝 프로파일 · Entitlements
  • 권한 요청 문구(…UsageDescription) — 비어 있으면 경고
  • 프레임워크 · 앱 확장 · Entitlements 목록은 줄이지 않고 전부

Android 서명 · 보안 · 16 KB

  • 인증서 지문 SHA-256 · SHA-1 · MD5, 카카오 · 페이스북용 키 해시
  • 권한 분류 · 기기 기능
  • 매니페스트 보안 설정: allowBackup · 평문 HTTP · 외부 공개 컴포넌트 · 딥링크
  • 네이티브 라이브러리 16 KB 페이지 정렬 검사
  • 빌드 · 구성 · 크기 구성 (DEX · 리소스 · ABI별 네이티브)

읽기 전용입니다. 파일을 바꾸지 않고, 옆에 아무것도 쓰지 않으며, 어디에도 올리지 않습니다.

OTA 배포

테스트 빌드, 링크 하나로 설치

이미 만든 IPA · APK 로 설치 페이지와 QR 을 만듭니다. 만든 파일을 https 서버에 올리기만 하면 됩니다.

iOS — Ad Hoc · Enterprise

  • manifest.plist · install.html · QR (itms-services:// 설치 링크)
  • IPA 를 읽어 번들 ID · 버전 · 빌드 · 앱 이름을 자동으로 채움
  • 변경 사항을 적으면 설치 페이지에 함께 들어감

Android — APK

  • install.html: 아이콘 · 버전 · SHA-256 · 설치 안내 · 변경 사항
  • 설치 페이지 주소를 담은 QR
  • APK 를 읽어 패키지 · 버전 · 앱 이름 · 아이콘을 자동으로 채움

호스팅은 직접

  • 저장할 폴더를 고르면 그곳에 파일을 만듭니다
  • 앱은 어디에도 올리지 않습니다 — 팀의 https 서버에 직접 올리세요
  • iOS 는 https 만 허용하고 Safari 에서 열어야 설치됩니다
