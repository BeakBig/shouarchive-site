ShouArchive

プロファイル管理 · ビルド成果物検査 — リリース直前に確認すべきことを、1 つのアプリで。

IPA・APK・AAB を開いて、ストアに表示される情報や署名・権限をその場で確認し、プロビジョニングプロファイルを有効期限とあわせて管理します。ファイルは Mac 内でのみ読み取ります。ビルド・アプリのアップロード・端末へのインストール・ストア配信まで、同じアプリで続けて行えます。

プロファイル

プロビジョニングプロファイルを、有効期限から端末登録まで

Xcode がインストールしたプロファイルを一目で確認。App Store Connect API キーがあれば、ダウンロード・作成・更新までアプリの中で完結します。

インストール済みプロファイル

  • すべての行に D-N 有効期限バッジ — 30 日以内に期限が切れるものはオレンジ、期限切れは赤
  • フィルター: 全体 · 新規 · 重複 / 有効 · まもなく期限切れ · 期限切れ、チーム・証明書の種類（Developer · Distribution · Ad Hoc · Enterprise）別
  • 詳細: 端末 UDID・含まれる証明書（SHA-1 · SHA-256）・Entitlements を項目ごとにコピー
  • 詳細は一覧に入るとバックグラウンドで自動的に読み込み、名前・バンドル ID・UUID はもちろん端末 UDID でもすぐに検索
  • 2 つのプロファイルを選び、上部の比較バーで並べて比較 — 端末・証明書・Entitlements の差分
  • .mobileprovision をドラッグ＆ドロップで追加、複数選択して削除

App Store Connect API

  • 「API キー」タブでキーをチームごとに複数保存・管理 — 保存時にチームを自動で読み取ります
  • チームのプロファイル一覧を取得し、未インストールのものだけを選んでインストール
  • 登録済み端末の一覧と新しい端末の登録 — 種類ごとの上限を表示（例: iPhone 3 / 100）
  • 新しいプロファイルの作成: 種類・プラットフォーム・バンドル ID・証明書・端末
  • 端末が変わったときや期限が近いときは作り直し・更新

使うのは Issuer ID・Key ID・.p8 だけです。キーファイルは Mac に置いたまま、リクエストトークンはローカルで署名します。

履歴

  • 名前・バンドル ID・UUID・UDID で検索
  • 誰がいつどのプロファイルを変更したのかを振り返りたいときに

ビルド成果物検査

IPA・APK・AAB を、アップロードする前に開く

ファイルをドロップするだけで、外部ツールなしにその場で解析します。ストアに表示される情報から署名・権限・セキュリティ設定まで、すべての項目に説明が付いているので、初めて見る値もその場で理解できます。

ストア掲載情報

製品ページに表示される値のうち、成果物から読み取れるものを先に確認できます。

  • アイコン・名前・提供者・サイズ・対応言語
  • iOS: カテゴリ・互換性・ATT（トラッキング許可リクエスト）の有無・プライバシーマニフェストの要約
  • Android: ダウンロードサイズ・必要な Android バージョン・権限数・アプリ内課金・広告 ID・対応デバイス

iOS の署名と権限

  • 署名・プロビジョニングプロファイル・Entitlements
  • 権限の利用目的説明（…UsageDescription）— 空のものがあれば警告
  • フレームワーク・アプリ拡張・Entitlements の一覧を省略せずすべて表示

Android の署名・セキュリティ・16 KB

  • 証明書フィンガープリント SHA-256 · SHA-1 · MD5、Kakao・Facebook 用のキーハッシュ
  • 権限の分類・端末機能
  • マニフェストのセキュリティ設定: allowBackup・平文 HTTP・外部公開コンポーネント・ディープリンク
  • ネイティブライブラリの 16 KB ページ整列チェック
  • ビルド・構成・サイズの内訳（DEX・リソース・ABI ごとのネイティブ）

読み取り専用です。ファイルを変更せず、隣に何も書き込まず、どこにもアップロードしません。
