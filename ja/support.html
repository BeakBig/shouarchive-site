サポート

ShouArchive の使用中に困ったことがあればお知らせください。下のよくある質問に答えがあるかもしれません。

お問い合わせ support@beakbig.com 送信するとすぐに受付確認メールが届き、担当者が確認のうえ1日以内に返信します。不具合報告のコツはいちばん下にあります。

はじめに

プロファイルはどこから読み込みますか？

Xcode がプロビジョニングプロファイルを保存するフォルダをアプリが直接読み込みます。別途許可や設定は必要ありません。

  • ~/Library/Developer/Xcode/UserData/Provisioning Profiles — Xcode 16 以降
  • ~/Library/MobileDevice/Provisioning Profiles — それ以前の Xcode

ほかの場所にある .mobileprovision ファイルは、ウインドウにドラッグ＆ドロップするか「ファイルから追加…」で開けます。

どのファイルに対応していますか？
  • ビルド成果物検査: .ipa（iOS タブ）、.apk · .aab（Android タブ）
  • プロファイル: .mobileprovision
  • API キー: App Store Connect からダウンロードした .p8

ファイルはドラッグ＆ドロップするか「ファイルを選択…」（⌘O）で開きます。

プロファイル · App Store Connect API

App Store Connect API キーはどう作成しますか？
  1. App Store Connect › ユーザとアクセス › 統合 › App Store Connect API を開きます。
  2. チームキー（Team key）を作成します。プロファイルと端末を参照・作成するには、通常 Admin の役割が必要です。
  3. アプリ画面下部のメニューの 「API キー」タブ（または「設定」（⌘,）›「API キー」）で「新しいキー」をクリックし、Issuer ID、Key ID、ダウンロードした .p8 ファイルを登録します。AuthKey_XXXXXXXX.p8 ファイルを選ぶと Key ID は自動で入力され、チームは保存時に Apple から読み込みます（読み込めない場合は手動で選ぶよう案内します）。貼り付けたときに混ざった空白・改行は自動で取り除かれます。

.p8 ファイルは Apple から一度しかダウンロードできないので、安全な場所に保管してください。Apple ID や 2 ファクタ認証は使いません。

API キーはどこに保存され、どこへ送信されますか？

.p8 ファイルは選んだ場所にそのまま置かれ、アプリはそのファイルの場所（セキュリティスコープ付きブックマーク）だけを記憶します。Apple に送るリクエストトークンは Mac 上で署名し、キー自体は Apple の App Store Connect API（api.appstoreconnect.apple.com）以外のどこにも送られません。アプリでキーを削除しても、.p8 ファイルは削除しません。

「まもなく期限切れ」と D-N バッジの基準は？

有効期限まで 30 日以内であれば「まもなく期限切れ」に分類し、残り日数を D-N（オレンジ）バッジで表示します。すでに過ぎたものは「期限切れ」（赤）です。「新規」は最近作成したプロファイル、「重複」は同じチーム・同じ App ID・同じ種類のプロファイルが 2 つ以上あるときです。

「証明書」カードには何が表示されますか？

この Mac のキーチェーンにあるコード署名証明書を、期限切れのものも含めて表示します。プロファイルの中に含まれる証明書は、詳細画面と比較画面で確認できます（SHA-1 · SHA-256 をコピー可能）。

端末登録の上限は？

Apple Developer アカウントでは、メンバーシップの 1 年ごとに、端末の種類（iPhone · iPad · Mac …）ごとに 100 台まで登録できます。無効にした端末も、メンバーシップを更新するまでは枠を使います。「プロファイル」›「プロファイルダウンロード」の「端末」タブの上部に、種類ごとの使用数（例: iPhone 3 / 100）が表示されます。

ビルド成果物検査

検査するとファイルが変更されたり、どこかにアップロードされたりしますか？

いいえ。ファイルは読み取るだけです。元のファイルを変更せず、隣に結果ファイルを書き込まず、どのサーバーにも送信しません。検査結果はアプリのウインドウにだけ表示されます。

項目名の意味がわかりません。

点線の下線がある項目名（権限・端末機能・マニフェスト設定・証明書フィンガープリント・Entitlements など）をクリックすると、概要 · 詳細 · 注意点の説明がポップオーバーで表示されます。16 KB カードはタイトル横の ⓘ をクリックしてください。

16 KB ページサイズのチェックでは何を確認しますか？

Android 15 から 16 KB のメモリページを使う端末があり、Google Play はそれに対応したネイティブライブラリを求めています。アプリは 64 ビット（arm64-v8a · x86_64）の .so ファイルの ELF LOAD 整列と、APK 内に無圧縮で保存された .so の 16 KB 境界を確認し、非対応のライブラリを一覧で表示します。

価格 · ライセンス

価格はいくらで、何が含まれますか？

初回購入は US$29（税別）で、ライセンスと 1 年間のアップデートが含まれます。1 つのライセンスキーで Mac 2 台で使えます。プロファイル管理・API キー・ビルド成果物検査・ビルド・アプリのアップロード・端末へのインストール・依存関係チェック・OTA インストールファイル・ストア配信がすべて含まれます。体験期間中・体験期間の終了後・購入後に使える機能は、価格ページの表にまとめています。

いつ発売されますか？

価格は決まりました — 初回購入 US$29（1 年間のアップデート付き）、その後のアップデートは年 US$15 です（税別）。発売日はまだ決まっていません。決まり次第、価格ページとダウンロードページでお知らせします。ご不明な点は support@beakbig.com までお送りください。

ライセンスキーはどうやって登録しますか？

決済が完了すると、決済完了画面とメールでキーを受け取れます。ShouArchive をインストールした Mac で、決済完了画面の「ShouArchive で開く」またはメールの「アプリでそのまま登録」リンクを押すと、アプリがこの Mac に登録するか確認します。「登録」を押せば完了です。リンクが開かない場合は「設定 › ライセンス › キーを入力…」で決済に使ったメールアドレスとキーを入力してください。アプリから購入した場合は、その Mac で「自動確認」を押すだけでも登録できます。決済しただけでは Mac は登録されないので、別の Mac 用に購入した場合はその Mac で登録してください。

ライセンスキーをなくしました

キーの再送に決済に使ったメールアドレスを入力すると、同じキーをそのアドレスに再送します。アプリの「設定 › ライセンス › キーを再送…」からも依頼できます。キーは購入時のメールアドレスにのみ送信します。お支払い時にメールアドレスを誤って入力した場合は、お支払い日とカード明細の表示内容を support@beakbig.com までお知らせください。

ライセンスキーが他の人に知られたかもしれません

キーの変更にお支払いに使ったメールアドレスを入力すると、確認リンクを送ります（アプリの「設定 › ライセンス › キーを変更…」からも依頼できます）。リンクを開いて「キーを変更」を押すと、新しいキーを購入時のメールアドレスに送り、以前のキーは使えなくなり、登録済みの Mac はすべて解除されます。使い続ける Mac は新しいキーで登録し直してください。2 台目以降の Mac が登録されるたびに購入時のメールアドレスへお知らせが届くので、心当たりがなければそのメールのリンクからすぐに変更できます。

別の Mac に移すには？

今使っている Mac で「設定 › ライセンス」の「解除」をクリックすると枠が空くので、新しい Mac で同じキーを登録してください。以前の Mac が使えず解除できない場合は、新しい Mac で登録するときに枠が埋まっていれば登録済み Mac の一覧（モデル名・登録日・最終使用日）が表示されます。使わなくなった Mac を「解除」すると、この Mac がすぐに登録されます（ほかの Mac の解除は 30 日に 3 回まで）。1 つのキーで同時に Mac 2 台まで使えます。

アップデート期間が終わるとアプリは使えなくなりますか？

いいえ。一度購入すればずっと使えます。アップデート期間内に公開されたバージョンは、期間の終了後もそのまま使えます。期間の終了後に公開されたバージョンだけは、アップデートを更新（年 US$15）しないとインストールできません。更新は自動で行われ、いつでも止められます。期間が終わったあとに改めて更新すると、その決済日から新たに 1 年が始まります。

体験期間が終わったら？

14 日間の体験版は支払い方法の登録なしで始めるため、終了しても自動で課金されることはありません。ライセンスキーなしで体験期間が終わると、プロファイル管理とビルド成果物検査だけが引き続き使え、ビルド・アップロード・端末へのインストール・依存関係チェック・OTA・ストア配信は、購入後に「設定 › ライセンス」にキーを入力すると再び使えるようになります。

一般

表示言語を変えるには？

ツールバーの地球儀メニューで言語を選び、「今すぐ再起動」をクリックすると、その言語で開き直します。言語はアプリを再起動すると適用され、作業中の内容はそのまま残ります。한국어 · English · 日本語 · 简体中文 · 繁體中文 · Español に対応しています。

テーマと文字サイズは？

ツールバーのテーマメニューで、カラーテーマ（Black & White · ShouArchive）とライト · ダーク · システム設定を選びます。文字サイズは「表示」メニューの「テキストを大きく ⌘+ · 小さく ⌘- · デフォルトのサイズ ⌘0」、または「設定」（⌘,）›「外観」で 85 %〜150 % の範囲で変更できます。

動作環境

macOS 15 Sequoia 以降。Apple Silicon と Intel Mac の両方に対応しています。プロファイルのダウンロード・作成・端末登録には App Store Connect API キーが必要で、ライセンスの確認・アップデートの確認・アプリのアップロード・ストア配信にはインターネット接続が必要です。ビルド成果物検査とインストール済みプロファイルの閲覧はインターネットなしで動作します。

不具合を報告するには？

support@beakbig.com まで、以下の内容を添えてお送りいただければ、早く確認できます。

アプリ内では「ヘルプ」メニュー ›「お問い合わせ · ご提案を送信…」（または「設定」（⌘,）›「メールを作成…」）からすぐに書けます。アプリのバージョンと macOS の情報は本文の下に自動で添付されます。

  • macOS のバージョン（Apple メニュー › この Mac について）
  • アプリのバージョン（ShouArchive メニュー › ShouArchive について）
  • どの順番で何をしたときに、何が起きたか
  • 可能であれば、スクリーンショットやエラーメッセージ

IPA · APK · プロファイルのファイルを送る必要はありません。どうしても必要な場合は別途お願いします。お送りいただく際は、キーファイル（.p8）や機密情報が含まれていないかご確認ください。
