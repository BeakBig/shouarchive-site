サポート

はじめに

プロファイルタブでフォルダの許可を求められます。なぜですか？

Mac App Store 版は macOS のサンドボックス内で動作します。サンドボックス化されたアプリは、ユーザーが明示的に選んだフォルダしか読み取れません。Xcode がプロビジョニングプロファイルを保存するフォルダはアプリの外にあるため、一度だけ許可していただく必要があります。

プロファイルタブのフォルダボタンをクリックすると、そのフォルダが選択された状態でオープンパネルが開きます。何も変更せず、そのまま「許可」を押してください。許可は次回以降の起動でも記憶されます（macOS のセキュリティスコープ付きブックマーク）。

アプリが読み取るフォルダ:

  • ~/Library/Developer/Xcode/UserData/Provisioning Profiles — Xcode 16 以降
  • ~/Library/MobileDevice/Provisioning Profiles — それ以前の Xcode

~/Library は Finder では標準で非表示です。オープンパネルで ⌘⇧G を押してパスを貼り付けると、直接移動できます。フォルダを許可したくない場合でも、.mobileprovision ファイルをウインドウにドラッグするか「ファイルから追加…」を使えば開けます。

対応しているファイル形式は？
  • ビルド成果物検査: .ipa（iOS タブ）、.apk と .aab（Android タブ）
  • プロファイル: .mobileprovision
  • API キー: App Store Connect からダウンロードした .p8 ファイル

ファイルをウインドウにドロップするか、「ファイルを選択…」（⌘O）で開きます。

この版に IPA/APK のビルドや書き出しがないのはなぜですか？

Mac App Store のアプリはサンドボックスが必須で、サンドボックス内では xcodebuild や gradle のような外部プログラムを起動できません。そのためこの版は、検査・プロファイル の 2 つに絞っています。ビルド成果物検査も外部ツールに依存せず、アプリ内蔵のパーサーが IPA・APK・AAB を直接読み取ります。

プロファイルと App Store Connect API

App Store Connect API キーはどう作りますか？
  1. App Store Connect › ユーザーとアクセス › 統合 › App Store Connect API を開きます。
  2. チームキーを生成します。プロファイルと端末の取得・作成には、通常 Admin ロールが必要です。
  3. アプリの「プロファイルダウンロード」›「API キー」に Issuer ID、Key ID、ダウンロードした .p8 ファイルを入力します。AuthKey_XXXXXXXX.p8 ファイルを選ぶと Key ID は自動的に入力されます。

.p8 ファイルは Apple から一度しかダウンロードできないため、安全な場所に保管してください。アプリが Apple ID や 2 ファクタ認証コードを使うことはありません。

API キーはどこに保存され、どこへ送られますか？

.p8 ファイルは置いた場所にそのまま残り、アプリはその参照（セキュリティスコープ付きブックマーク）だけを記憶します。リクエストトークンは Mac 上で署名され、キー自体がどこかへ送られることはありません。アプリが通信するのは Apple の App Store Connect API（api.appstoreconnect.apple.com）だけです。アプリでキーを削除しても、.p8 ファイルは削除されません。

「まもなく期限切れ」と D-N バッジの意味は？

有効期限まで 30 日以内のプロファイルが「まもなく期限切れ」で、残り日数をオレンジ色の D-N バッジで表示します。期限を過ぎたものは「期限切れ」（赤）です。「新規」は最近作成されたもの、「重複」は同じチーム・App ID・種類のプロファイルが 2 つ以上あることを示します。

「証明書」カードが空です。

キーチェーンにあるコード署名証明書の一覧はサンドボックス内から読み取れないため、Mac App Store 版ではこのカードは空になります。各プロファイルに含まれる証明書は、詳細表示と比較表示でこれまでどおり確認でき、SHA-1 と SHA-256 のコピーボタンも使えます。

端末は何台まで登録できますか？

Apple Developer アカウントでは、メンバーシップ年ごとに種類別（iPhone、iPad、Mac など）で 100 台まで登録できます。無効にした端末も、メンバーシップが更新されるまでは枠を占有します。端末タブに種類ごとの現在の使用状況（例: iPhone 3 / 100）が表示されます。

ビルド成果物検査

検査するとファイルが変更されたり、アップロードされたりしますか？

いいえ。ファイルは読み取るだけです。元のファイルは変更されず、隣に結果ファイルを書き込むこともなく、どのサーバーにも送信しません。結果はアプリのウインドウにのみ表示されます。

項目の意味がわかりません。

点線の下線が付いた項目名（権限、端末機能、マニフェスト設定、証明書フィンガープリント、Entitlements など）をクリックすると、概要 · 詳細 · 注意点を説明するポップオーバーが開きます。16 KB カードは、タイトル横の ⓘ をクリックしてください。

16 KB ページサイズのチェックでは何を確認しますか？

Android 15 以降、一部の端末は 16 KB のメモリページを使用しており、Google Play はこれに対応したネイティブライブラリを求めています。アプリは 64 ビット（arm64-v8a、x86_64）の .so ファイルの ELF LOAD アライメントと、APK 内に無圧縮で格納された .so ファイルについてはアーカイブ内での 16 KB 境界を確認し、対応していないライブラリを一覧表示します。

一般

言語を変更するには？

ツールバーの地球儀メニューを開いて言語を選び、「今すぐ再起動」を確定します。アプリはその言語で再起動し、作業中の内容はそのまま保持されます。対応言語: 日本語、English、한국어、简体中文、繁體中文、Español。

テーマと文字サイズは？

ツールバーでライト・ダーク・システム設定から選びます。文字サイズは表示メニュー（文字を大きく ⌘+、文字を小さく ⌘-、デフォルトのサイズ ⌘0）または設定（⌘,）› 画面で 85 % から 150 % まで変更できます。

動作環境

macOS 15 Sequoia 以降、Apple Silicon または Intel の Mac。App Store Connect API キーが必要なのはプロファイルのダウンロード・作成と端末登録だけで、それ以外の機能はオフラインで動作します。

問題を報告するには？

beakbigkb@gmail.com 宛てに、次の情報を添えてお送りいただくと迅速に確認できます。

  • macOS のバージョン（Apple メニュー › この Mac について）
  • アプリのバージョン（ShouArchive メニュー › ShouArchive について）
  • 行った操作の手順と、何が起きたか
  • 可能であればスクリーンショット、または表示されたエラーの文言

IPA・APK・プロファイルのファイルを添付する必要はありません。必要な場合は別途お願いします。送信する前に、キーファイル（.p8）や機密情報が含まれていないことを確認してください。
