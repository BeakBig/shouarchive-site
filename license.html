라이선스 키 다시 받기

결제할 때 쓴 이메일 주소로 같은 키를 다시 보냅니다.

요청을 받았습니다. 이 주소로 구매한 기록이 있으면 몇 분 안에 키가 도착합니다. 오지 않으면 스팸함을 확인하세요.

이메일 주소를 확인해 주세요.

지금은 요청을 보내지 못했습니다. 잠시 뒤 다시 시도하거나 support@beakbig.com 으로 문의해 주세요.

알아 두기

  • 키는 결제할 때 쓴 이메일 주소로만 보냅니다. 구매 기록이 없는 주소로는 아무것도 보내지 않습니다.
  • 같은 키를 다시 보냅니다. 이미 등록한 Mac 은 그대로 쓸 수 있습니다.
  • 짧은 시간에 여러 번 요청하면 잠시 보내지 않습니다.
  • 결제할 때 이메일을 잘못 입력했다면 결제한 날짜와 카드 명세서에 찍힌 내용을 support@beakbig.com 으로 알려 주세요.
  • 키가 다른 사람에게 알려진 것 같다면 키 바꾸기 로 새 키를 받으세요. 예전 키는 더 쓸 수 없게 됩니다.

키를 받은 뒤

  1. 메일의 「앱에서 바로 등록하기」 링크를 ShouArchive 가 설치된 Mac 에서 누르세요.
  2. 링크가 열리지 않으면 ShouArchive 의 설정 › 라이선스 › 「키 입력…」 에 구매 이메일과 키를 넣으세요.
