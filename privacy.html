개인정보 처리방침

ShouArchive (macOS) · 시행일 2026년 10월 3일 · 개발자 BeakBig · Mac App Store 판과 상용 판

이 문서는 두 가지 판을 함께 설명합니다. Mac App Store 판(1 – 7항)은 지금처럼 어떤 개인정보도 수집하지 않습니다. 분석 도구 · 추적 · 광고 · 계정이 없고, 검사하는 파일은 Mac 안에서만 읽으며, 네트워크는 사용자가 직접 등록한 App Store Connect API 키로 Apple 과 통신할 때만 씁니다. 상용 판(9 – 13항)은 웹에서 직접 구독하는 판으로, 라이선스를 확인할 때만 라이선스 키 · 기기 식별값 · 앱 버전을 라이선스 서버로 보내고, 결제는 Paddle이 판매대행으로 처리합니다. 8항의 변경 통지와 14항의 문의를 두 판에 함께 적용합니다. 두 판은 서로 연동되지 않습니다.

1. 수집하는 정보 — Mac App Store 판

이 판에서는 없습니다. 앱은 다음 중 어느 것도 하지 않습니다.

  • 사용 통계 · 오류 보고 등 분석(analytics) 데이터를 모으지 않습니다.
  • 사용자나 기기를 추적하지 않고, 광고를 보여 주지 않습니다.
  • 계정이나 로그인이 없습니다.
  • 네트워크와 통신하는 제3자 SDK 를 포함하지 않습니다.

2. 파일 처리

산출물 검사와 프로파일 관리에서 다루는 파일(IPA · APK · AAB · .mobileprovision)은 사용자의 Mac 에서만 읽습니다. 파일의 내용이나 그로부터 얻은 정보(번들 ID · 서명 인증서 · 권한 목록 등)는 앱 창에 표시될 뿐, 어디로도 전송되지 않습니다. 산출물 검사는 원본 파일을 바꾸지 않습니다.

3. 네트워크 사용

앱이 네트워크를 쓰는 경우는 하나뿐입니다. 사용자가 자신의 App Store Connect API 키(Issuer ID · Key ID · .p8)를 등록하고 관련 기능을 실행하면, 앱은 Apple 의 App Store Connect API(api.appstoreconnect.apple.com)에 접속합니다.

프로파일 목록 · 다운로드앱이 서명한 인증 토큰
프로파일 생성 · 다시 만들기 · 갱신인증 토큰과 사용자가 고른 프로파일 종류 · 번들 ID · 인증서 · 기기

  • Apple 이 이 요청을 어떻게 처리하는지는 Apple 개발자 프로그램 약관과 Apple 의 개인정보 처리방침을 따릅니다.
  • API 키를 등록하지 않으면 앱은 네트워크에 접속하지 않습니다.

4. Mac 에 저장되는 것

  • 앱 설정(테마 · 언어 · 텍스트 크기 · API 키 정보 등)은 macOS 가 앱마다 제공하는 샌드박스 컨테이너 안에 저장됩니다.
  • 프로파일 폴더와 .p8 파일 접근은 사용자가 열기 패널에서 허용한 보안 스코프 북마크로 기억합니다. 이 북마크는 언제든 앱에서 지울 수 있습니다.
  • 프로파일 활동 기록(다운로드 · 생성 · 기기 등록 등)은 로컬에만 남고, 「기록 지우기」로 삭제할 수 있습니다.
  • 앱을 삭제하면 컨테이너와 함께 이 데이터도 사라집니다. .p8 파일 등 사용자가 직접 둔 파일은 앱이 지우지 않습니다.

5. 제3자 라이브러리

앱은 로딩 애니메이션 표시를 위해 오픈 소스 라이브러리 Lottie 를 포함합니다. 화면 표시에만 쓰이며 네트워크에 접속하거나 데이터를 수집하지 않습니다. 그 밖의 제3자 SDK 는 없습니다.

6. 공유와 판매

Mac App Store 판은 수집하는 정보가 없으므로 누구와도 공유하거나 판매하지 않습니다. 3항에 적은 Apple 과의 통신은 사용자의 요청으로, 사용자의 계정과 키를 써서 이루어집니다. 상용 판에서 나누는 대상은 11항의 라이선스 서버와 12항의 Paddle뿐이며, 그 밖의 제3자에게 팔거나 넘기지 않습니다[구현을 확인하고 확정하세요].

7. 아동

ShouArchive 는 소프트웨어 개발자를 위한 도구이며 아동을 대상으로 하지 않습니다. Mac App Store 판에서는 누구에게서도 개인정보를 수집하지 않습니다.

8. 변경

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다. 앱의 데이터 처리 방식이 실제로 달라지는 경우에는 앱 업데이트 설명에도 적습니다.

9. 상용 판 — 수집하는 정보

상용 판(이 사이트에서 직접 구독하는 판)은 구독 중 라이선스를 확인하기 위해서만 다음 값을 라이선스 서버로 보냅니다. 그 밖의 목적으로 쓰지 않으며, 전송은 모두 HTTPS 로 이루어집니다.

보내는 값내용왜 필요한가
라이선스 키구독을 판별하는 키구독이 유효한지 확인합니다
기기 식별값이 Mac 의 하드웨어 UUID 에 앱 전용 접두어를 붙여 SHA-256 으로 바꾼 값의 앞 32자. 하드웨어 UUID 원문 · 호스트 이름 · 사용자 이름은 보내지 않습니다. 하드웨어 UUID 를 읽지 못하면 앱이 처음 실행될 때 만든 무작위 설치 id 를 같은 방식으로 씁니다. Mac 이름이나 네트워크가 바뀌어도 값은 그대로입니다요금제가 허용한 기기 수를 넘었는지 확인합니다
앱 버전앱 버전 · 빌드 번호기능이 맞는지 확인하고 문제를 해결합니다
접근 기록기기 식별값의 해시, 앱 버전, 시각, 짧은 오류 사유장애에 대응하고 문제를 해결합니다

언제 무엇을 보내나요.

  • 활성화 — 라이선스 키, 구매 이메일, 기기 식별값, 설치 식별값, 앱 버전, macOS 버전
  • 라이선스 확인 — 약 12 시간마다 라이선스 키, 기기 식별값, 설치 식별값, 앱 버전
  • 해제 — 라이선스 키, 기기 식별값
  • 결제 시작 — 플랜(월 · 연), 기기 식별값, 설치 식별값, 앱 버전. 결제 자체는 Paddle 의 결제 페이지에서 합니다

서버에 저장되는 것. 라이선스 키와 기기 · 설치 식별값은 원문을 저장하지 않고 해시(SHA-256 · HMAC-SHA256)만 저장합니다. 앱 버전과 구매 이메일은 그대로 저장하며, 구매 이메일은 라이선스 조회와 키 발송에 씁니다. Paddle 에서는 구독 · 고객 · 거래 id, 구독 상태, 가격 id, 다음 결제일, 예약된 변경을 받습니다. 이름 · 주소 · 카드 정보는 받지 않습니다.

저장하지 않는 것. IP 주소, 요청 헤더와 요청 본문, macOS 버전(받기만 하고 저장하지 않음), 이름 · 주소, 카드 번호, 마케팅 동의, 사용 통계.

  • 이 값은 앱이 동작하는 상용 판에서만 보내집니다. Mac App Store 판은 네트워크에 접속하지 않으므로(3항) 아무것도 보내지 않습니다.
  • 사용자를 알아낼 수 있는 값(사용자 이름 · 기기에 직접 붙인 이름 등)은 라이선스 확인에 쓰지 않습니다.
  • 파일(IPA · APK · AAB · .mobileprovision)의 내용과 산출물 검사 결과는 라이선스 서버로 보내지 않습니다.
  • 광고 · 추적 · 행동 분석 SDK 는 상용 판에도 넣지 않습니다[구현을 확인하고 확정하세요].

11. 상용 판 — 결제와 Paddle

상용 판의 결제는 Paddle(paddle.com)이 판매대행(Merchant of Record)으로 처리합니다. Paddle이 고객에 대한 판매자가 되어 결제 수단 확인, 세금 계산과 부과, 영수증 발행, 환불 처리를 맡습니다. 결제 수단 정보는 Paddle이 보관하며 이 사이트의 서버를 지나지 않습니다.

  • Paddle이 수집 · 처리하는 것 — 이름, 주소, 이메일 주소, 결제 수단 정보와 결제 내역, 청구 주소, 세금 번호, IP 주소, 위치 정보, 기기 · 브라우저 정보, 동의 기록 등. 이는 Paddle 개인정보 처리방침에 따라 처리되며, Paddle 은 법적 의무를 위해 거래 데이터를 5년 보관합니다.
  • 판매자(저)에게 넘어오는 것 — 구매자의 이름 · 주소 · 이메일 주소, 구매 내역, 대시보드에서 볼 수 있는 거래 분석. 카드 전체 번호와 보안 코드는 넘어오지 않습니다. 특별한 민감 정보 범주는 공유되지 않습니다.
  • 판매자와 Paddle은 이 데이터에 대해 각각 독립적인 데이터 관리 주체입니다. 판매자는 받은 정보로 라이선스 발급, 결제 확인과 고객 문의에 대응할 뿐 다른 목적으로 쓰지 않습니다.
  • 결제에 관한 문의는 Paddle의 고객 지원 창구에서 받습니다. 환불 기준은 환불 정책에 적어 두었습니다.
  • Paddle이 대행하는 판매자 약관도 함께 적용됩니다: Paddle 이용약관, Paddle 구매자 약관.

13. 국외 이전

  • 받는 곳과 나라 — 상용 판의 라이선스 기록은 Cloudflare, Inc.(미국)로, 결제 정보는 Paddle.com Market Limited(영국)로 처리됩니다.
