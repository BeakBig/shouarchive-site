개인정보 처리방침

ShouArchive (macOS) · 시행일 2026년 9월 22일 · 개발자 BeakBig

요약. ShouArchive 는 어떤 개인정보도 수집하지 않습니다. 분석 도구 · 추적 · 광고 · 계정이 없고, 검사하는 파일은 Mac 안에서만 읽습니다. 네트워크는 사용자가 직접 등록한 App Store Connect API 키로 Apple 과 통신할 때만 씁니다.

1. 수집하는 정보

없습니다. 앱은 다음 중 어느 것도 하지 않습니다.

  • 사용 통계 · 오류 보고 등 분석(analytics) 데이터를 모으지 않습니다.
  • 사용자나 기기를 추적하지 않고, 광고를 보여 주지 않습니다.
  • 계정이나 로그인이 없습니다.
  • 네트워크와 통신하는 제3자 SDK 를 포함하지 않습니다.

2. 파일 처리

산출물 검사와 OTA 배포, 프로파일 관리에서 다루는 파일(IPA · APK · AAB · .mobileprovision)은 사용자의 Mac 에서만 읽습니다. 파일의 내용이나 그로부터 얻은 정보(번들 ID · 서명 인증서 · 권한 목록 등)는 앱 창에 표시될 뿐, 어디로도 전송되지 않습니다. 산출물 검사는 원본 파일을 바꾸지 않습니다.

OTA 배포 파일(manifest.plist · install.html · QR 이미지)은 사용자가 고른 폴더에만 씁니다. 앱은 이 파일을 어떤 서버에도 올리지 않습니다.

3. 네트워크 사용

앱이 네트워크를 쓰는 경우는 하나뿐입니다. 사용자가 자신의 App Store Connect API 키(Issuer ID · Key ID · .p8)를 등록하고 관련 기능을 실행하면, 앱은 Apple 의 App Store Connect API(api.appstoreconnect.apple.com)에 접속합니다.

기능Apple 에 보내는 것
프로파일 목록 · 다운로드앱이 서명한 인증 토큰
프로파일 생성 · 다시 만들기 · 갱신인증 토큰과 사용자가 고른 프로파일 종류 · 번들 ID · 인증서 · 기기
기기 목록 · 기기 등록인증 토큰과 사용자가 입력한 기기 이름 · UDID
  • .p8 개인 키 파일은 사용자의 Mac 에 그대로 있습니다. 앱은 파일 위치를 가리키는 참조(macOS 보안 스코프 북마크)만 저장하고, 요청에 필요한 토큰을 로컬에서 서명합니다. 키 자체를 Apple 을 포함한 어느 곳에도 보내지 않습니다.
  • Apple 이 이 요청을 어떻게 처리하는지는 Apple 개발자 프로그램 약관과 Apple 의 개인정보 처리방침을 따릅니다.
  • API 키를 등록하지 않으면 앱은 네트워크에 접속하지 않습니다.

4. Mac 에 저장되는 것

  • 앱 설정(테마 · 언어 · 텍스트 크기 · OTA 주소 설정 · API 키 정보 등)은 macOS 가 앱마다 제공하는 샌드박스 컨테이너 안에 저장됩니다.
  • 프로파일 폴더와 .p8 파일 접근은 사용자가 열기 패널에서 허용한 보안 스코프 북마크로 기억합니다. 이 북마크는 언제든 앱에서 지울 수 있습니다.
  • 프로파일 활동 기록(다운로드 · 생성 · 기기 등록 등)은 로컬에만 남고, 「기록 지우기」로 삭제할 수 있습니다.
  • 앱을 삭제하면 컨테이너와 함께 이 데이터도 사라집니다. .p8 파일 등 사용자가 직접 둔 파일은 앱이 지우지 않습니다.

5. 제3자 라이브러리

앱은 로딩 애니메이션 표시를 위해 오픈 소스 라이브러리 Lottie 를 포함합니다. 화면 표시에만 쓰이며 네트워크에 접속하거나 데이터를 수집하지 않습니다. 그 밖의 제3자 SDK 는 없습니다.

6. 공유와 판매

수집하는 정보가 없으므로 누구와도 공유하거나 판매하지 않습니다. 3항에 적은 Apple 과의 통신은 사용자의 요청으로, 사용자의 계정과 키를 써서 이루어집니다.

7. 아동

ShouArchive 는 소프트웨어 개발자를 위한 도구이며 아동을 대상으로 하지 않습니다. 누구에게서도 개인정보를 수집하지 않습니다.

8. 변경
