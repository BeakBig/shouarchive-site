개인정보 처리방침

ShouArchive (macOS) · 시행일 2026년 10월 15일 · 개발자 · 판매자 비그빅(Beakbig)

요약. 분석 도구 · 추적 · 광고 · 계정이 없습니다. 검사하는 파일은 Mac 안에서만 읽습니다. App Store Connect · Google Play 기능은 사용자가 직접 등록한 키로 Apple · Google 에 바로 접속합니다. 판매자에게 오는 것은 라이선스를 확인할 때의 라이선스 키 · 기기 식별값 · 앱 버전(5항)과, 결제를 판매대행하는 Paddle 이 넘겨주는 구매 정보(7항)뿐입니다.

1. 수집하지 않는 것

앱은 다음 중 어느 것도 하지 않습니다.

  • 사용 통계 · 오류 보고 등 분석(analytics) 데이터를 모으지 않습니다.
  • 사용자나 기기를 추적하지 않고, 광고를 보여 주지 않습니다.
  • 계정이나 로그인이 없습니다. 라이선스는 키 하나로 확인합니다.
  • 검사하는 파일의 내용, 프로젝트 소스, 빌드 결과물을 판매자에게 보내지 않습니다.

2. 파일 처리

산출물 검사와 프로파일 관리에서 다루는 파일(IPA · APK · AAB · .mobileprovision)은 사용자의 Mac 에서만 읽습니다. 파일의 내용이나 그로부터 얻은 정보(번들 ID · 서명 인증서 · 권한 목록 등)는 앱 창에 표시될 뿐, 어디로도 전송되지 않습니다. 산출물 검사는 원본 파일을 바꾸지 않습니다. 빌드 · 내보내기로 만든 파일은 사용자가 고른 폴더에만 저장됩니다.

3. 네트워크 사용

앱은 다음 경우에만 네트워크에 접속합니다. Apple · Google 로 가는 요청은 판매자의 서버를 거치지 않고 사용자의 Mac 에서 바로 갑니다.

기능접속하는 곳보내는 것
프로파일 목록 · 다운로드 · 생성 · 갱신, 기기 목록 · 등록, App Store 스토어 배포Apple App Store Connect API (api.appstoreconnect.apple.com)앱이 서명한 인증 토큰과, 사용자가 고르거나 입력한 값(프로파일 종류 · 번들 ID · 인증서 · 기기 이름 · UDID · 스토어 정보 · 스크린샷 등)
Google Play 업로드 · 스토어 배포Google Play Developer API (androidpublisher.googleapis.com · oauth2.googleapis.com)서비스 계정 키로 서명한 인증 요청과, 사용자가 고른 AAB · APK · 스토어 정보 · 스크린샷
빌드 · 앱 업로드 · 기기 설치Apple · Google 의 개발 도구(xcodebuild · gradle 등)가 접속하는 곳이 도구들이 각자의 방식으로 통신합니다. 의존성을 내려받는 저장소(Maven 등)도 여기에 포함됩니다
라이선스 활성화 · 확인 · 해제, 결제 시작판매자의 라이선스 서버5항
업데이트 확인판매자가 올려 두는 업데이트 목록일반적인 웹 요청(앱 이름 · 버전이 담긴 User-Agent). 업데이트 목록을 받기만 하고 다른 값은 보내지 않습니다
  • App Store Connect 의 .p8 개인 키와 Google 서비스 계정 키는 사용자의 Mac 에 그대로 있습니다. 앱은 요청에 필요한 토큰을 로컬에서 서명하며, 키 자체를 Apple · Google 을 포함한 어느 곳에도 보내지 않습니다.
  • Apple · Google 이 이 요청을 어떻게 처리하는지는 각 회사의 개발자 약관과 개인정보 처리방침을 따릅니다.

4. Mac 에 저장되는 것

  • 앱 설정(테마 · 언어 · 텍스트 크기 · 프로젝트 목록 등)은 macOS 의 사용자 설정 · 앱 지원 폴더에 저장됩니다.
  • API 키 본문은 이 Mac 의 키체인에 저장되고, iCloud 키체인으로 동기화되지 않습니다. 파일로 고른 키는 그 파일의 위치만 기억합니다.
  • 프로파일 활동 기록 · 빌드 기록은 로컬에만 남고, 앱에서 지울 수 있습니다.
  • 라이선스 키와 확인 결과는 이 Mac 에만 저장됩니다.
  • .p8 파일과 빌드 결과물 등 사용자가 직접 둔 파일은 앱이 지우지 않습니다.

5. 라이선스 확인 — 보내는 정보

앱은 라이선스와 업데이트 기간을 확인하기 위해서만 다음 값을 라이선스 서버로 보냅니다. 그 밖의 목적으로 쓰지 않으며, 전송은 모두 HTTPS 로 이루어집니다.

보내는 값내용왜 필요한가
라이선스 키구매한 라이선스를 판별하는 키라이선스가 유효한지, 업데이트 기간이 언제까지인지 확인합니다
기기 식별값이 Mac 의 하드웨어 UUID 에 앱 전용 접두어를 붙여 SHA-256 으로 바꾼 값의 앞 32자. 하드웨어 UUID 원문 · 호스트 이름 · 사용자 이름은 보내지 않습니다. 하드웨어 UUID 를 읽지 못하면 앱이 처음 실행될 때 만든 무작위 설치 id 를 같은 방식으로 씁니다. Mac 이름이나 네트워크가 바뀌어도 값은 그대로입니다라이선스가 허용한 기기 수(Mac 2대)를 넘었는지 확인합니다
앱 버전앱 버전 · 빌드 번호그 버전이 업데이트 기간 안에 나온 버전인지 확인하고, 문제를 해결합니다
접근 기록기기 식별값의 해시, 앱 버전, 시각, 짧은 오류 사유장애에 대응하고 문제를 해결합니다

언제 무엇을 보내나요.

  • 활성화 — 라이선스 키, 구매 이메일, 기기 식별값, 설치 식별값, 앱 버전, macOS 버전
  • 라이선스 확인 — 약 12 시간마다 라이선스 키, 기기 식별값, 설치 식별값, 앱 버전
  • 해제 — 라이선스 키, 기기 식별값
  • 결제 시작(구매 · 갱신) — 라이선스 키(갱신일 때), 기기 식별값, 설치 식별값, 앱 버전. 결제 자체는 Paddle 의 결제 화면에서 합니다

서버에 저장되는 것. 라이선스 키와 기기 · 설치 식별값은 원문을 저장하지 않고 해시(SHA-256 · HMAC-SHA256)만 저장합니다. 앱 버전과 구매 이메일은 그대로 저장하며, 구매 이메일은 라이선스 조회와 키 발송에 씁니다. Paddle 에서는 고객 · 거래 · 자동 갱신 id, 자동 갱신 상태(켜짐 · 꺼짐), 가격 id, 업데이트가 끝나는 날을 받습니다. 이름 · 주소 · 카드 정보는 받지 않습니다.

저장하지 않는 것. IP 주소, 요청 헤더와 요청 본문, macOS 버전(받기만 하고 저장하지 않음), 이름 · 주소, 카드 번호, 마케팅 동의, 사용 통계.

  • 사용자를 알아낼 수 있는 값(사용자 이름 · 기기에 직접 붙인 이름 등)은 라이선스 확인에 쓰지 않습니다.
  • 파일(IPA · APK · AAB · .mobileprovision)의 내용과 산출물 검사 결과는 라이선스 서버로 보내지 않습니다.
  • 광고 · 추적 · 행동 분석 SDK 는 앱에 넣지 않습니다.

6. 라이선스 서버와 보관

  • 라이선스 서버는 판매자 비그빅(Beakbig)(사업자등록번호 613-40-01820) · 연락처 support@beakbig.com가 운영합니다. 서버는 Cloudflare, Inc.(미국)의 Workers 를 쓰고, 데이터베이스는 아시아 · 태평양 지역(그 지역 안의 실제 위치는 Cloudflare 가 정함)에 있습니다.
  • 보내는 값과 라이선스 상태(발급 · 업데이트 기간 · 해지)는 라이선스가 있는 동안 보관합니다. 업데이트 기간이 끝나도 라이선스는 남으므로 지우지 않습니다. 환불 · 지불 거절(chargeback)로 라이선스가 해지되면 그로부터 2년 뒤에 지우거나 익명화하고(지금은 운영자가 직접 처리합니다), 삭제를 요청하시면 그때 지웁니다. 기간이 짧은 기록은 매일 자동으로 지웁니다 — 접근 기록 30일, 결제 알림(웹훅) 처리 기록 90일, 키 발송 기록 365일(받는 주소는 해시만 보관), 처리되지 않은 발급 대기 7일. 삭제 요청을 받으면 본인 확인 뒤 라이선스를 해지하고 남은 기록을 삭제합니다 — 삭제하면 그 라이선스로는 앱을 쓸 수 없습니다.
  • 이 서버에 저장되는 값은 5항에 적은 것과 같습니다. 결제 수단 정보, 카드 번호, 은행 계좌는 저장되지 않습니다.
  • 서버는 Cloudflare, Inc.(미국 회사)의 Workers 로 이용자와 가까운 Cloudflare 데이터센터에서 실행되고, 데이터베이스는 아시아 · 태평양 지역(그 지역 안의 실제 위치는 Cloudflare 가 정함)에 있습니다. 결제는 Paddle.com Market Limited(영국)가 판매대행(merchant of record)으로서 처리합니다.
  • 라이선스 키는 이메일 발송 서비스 Resend, Inc.(미국)를 통해 보냅니다. Resend 에는 키 발송에 필요한 받는 이메일 주소와 라이선스 키가 담긴 메일 본문만 넘깁니다.
  • 라이선스 서버에 저장된 내역을 직접 내려받거나 삭제를 요청하려면 11항의 방법으로 알려 주세요.

7. 결제와 Paddle

결제는 Paddle(paddle.com)이 판매대행(Merchant of Record)으로 처리합니다. Paddle이 고객에 대한 판매자가 되어 결제 수단 확인, 세금 계산과 부과, 영수증 발행, 환불 처리를 맡습니다. 결제 수단 정보는 Paddle이 보관하며 이 사이트의 서버를 지나지 않습니다.

  • Paddle이 수집 · 처리하는 것 — 이름, 주소, 이메일 주소, 결제 수단 정보와 결제 내역, 청구 주소, 세금 번호, IP 주소, 위치 정보, 기기 · 브라우저 정보, 동의 기록 등. 이는 Paddle 개인정보 처리방침에 따라 처리되며, Paddle 은 법적 의무를 위해 거래 데이터를 5년 보관합니다.
  • 판매자(저)에게 넘어오는 것 — 구매자의 이름 · 주소 · 이메일 주소, 구매 내역, 대시보드에서 볼 수 있는 거래 분석. 카드 전체 번호와 보안 코드는 넘어오지 않습니다. 특별한 민감 정보 범주는 공유되지 않습니다.
  • 판매자와 Paddle은 이 데이터에 대해 각각 독립적인 데이터 관리 주체입니다. 판매자는 받은 정보로 라이선스 발급, 결제 확인과 고객 문의에 대응할 뿐 다른 목적으로 쓰지 않습니다.
  • 결제에 관한 문의는 Paddle의 고객 지원 창구에서 받습니다. 환불 기준은 환불 정책에 적어 두었습니다.
  • Paddle이 대행하는 판매자 약관도 함께 적용됩니다: Paddle 이용약관, Paddle 구매자 약관.

8. 제3자 라이브러리

  • Lottie — 로딩 애니메이션 표시용 오픈 소스 라이브러리. 화면 표시에만 쓰이며 네트워크에 접속하거나 데이터를 수집하지 않습니다.
  • Sparkle — 앱 업데이트를 확인하고 설치하는 오픈 소스 라이브러리. 3항의 업데이트 확인에만 쓰이며, 시스템 정보 보내기는 켜 두지 않습니다.

그 밖에 네트워크와 통신하는 제3자 SDK 는 없습니다.

9. 공유와 판매

판매자가 개인정보를 나누는 대상은 6항의 라이선스 서버(Cloudflare) · 키 발송 서비스(Resend)와 7항의 Paddle뿐이며, 그 밖의 제3자에게 팔거나 넘기지 않습니다. 3항에 적은 Apple · Google 과의 통신은 사용자의 요청으로, 사용자의 계정과 키를 써서 이루어집니다.

10. 아동

ShouArchive 는 소프트웨어 개발자를 위한 도구이며 아동을 대상으로 하지 않습니다. 만 14세 미만의 개인정보를 알면서 수집하지 않습니다.

11. 개인정보 주체의 권리

이용자는 개인정보에 대해 열람 · 정정 · 삭제 · 처리 제한 · 수집 거부(결정에 따른 중지)의 권리를 가집니다.

  • 라이선스 서버에 있는 기록 — support@beakbig.com으로 요청해 주세요. 본인 확인 후 요청을 받은 날부터 10일 이내에 처리하고, 그 결과를 알려 드립니다.
  • Paddle이 보관한 결제 정보 — Paddle의 정책과 절차에 따라 처리됩니다. 필요한 정보는 Paddle에 직접 요청해 주시면 됩니다.
  • 거부할 수 있는 부분 — 라이선스 확인은 구매한 라이선스를 쓰기 위한 필수 처리입니다. 이를 거부하면 라이선스로 여는 기능을 쓸 수 없습니다.
  • 법정대리인이나 대리인이 요청하는 경우에는 위임 관계를 확인한 뒤 처리합니다.

이 방침은 대한민국 개인정보 보호법을 기준으로 작성되었습니다. EU · EEA · 영국 이용자에게는 GDPR 와 UK GDPR 가 정한 권리도 똑같이 보장합니다.

12. 국외 이전

  • 받는 곳과 나라 — 라이선스 기록은 Cloudflare, Inc.(미국)로, 결제 정보는 Paddle.com Market Limited(영국)로, 키 발송 메일은 Resend, Inc.(미국)로 처리됩니다.
  • 저장 위치 — 라이선스 기록은 아시아 · 태평양 지역의 데이터베이스(Cloudflare D1)에 저장되고, 요청은 이용자와 가까운 Cloudflare 데이터센터에서 처리됩니다.
  • 언제 · 어떻게 — 활성화 · 라이선스 확인 · 결제(구매 · 갱신)를 시작할 때, 그리고 라이선스 키를 이메일로 보낼 때 네트워크로 보냅니다.
  • 항목 · 목적 · 보관 기간 — 5항과 6항에 적은 것과 같습니다.
  • 보호 조치 — Cloudflare 는 데이터 처리 약관(EU 표준계약조항 포함)을 따르고, Paddle 은 판매대행자로서 자기 개인정보 처리방침에 따라 결제 정보를 처리합니다.
  • 거부 방법과 결과 — 라이선스를 쓰지 않으면 이전이 일어나지 않습니다. 그 경우 체험 기간이 지나면 프로파일 관리와 산출물 검사만 쓸 수 있습니다.
