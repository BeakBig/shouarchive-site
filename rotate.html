라이선스 키 바꾸기

키가 다른 사람에게 알려진 것 같을 때 새 키로 바꿉니다.

아래 단추를 누르면 라이선스 키가 바뀝니다. 예전 키는 더 쓸 수 없고 등록된 Mac 이 모두 해제되며, 새 키는 구매 이메일로 갑니다.

지금은 키를 바꾸지 못했습니다. 잠시 뒤 다시 눌러 주세요.

키를 바꿨습니다. 새 키를 구매 이메일()로 보냈습니다. 계속 쓸 Mac 에서 메일의 링크를 누르면 다시 등록됩니다.

키를 바꿨지만 새 키 메일을 보내지 못했습니다. 키 다시 받기 에 구매 이메일을 넣으면 새 키를 받을 수 있습니다.

이미 쓴 링크이거나 잘못된 링크입니다. 키를 이미 바꿨다면 새 키 메일을 확인하세요. 다시 바꾸려면 아래에서 확인 메일을 새로 받으세요.

링크의 유효 시간이 지났습니다. 아래에서 확인 메일을 새로 받으세요.

환불 또는 지급 거절로 철회된 라이선스라 키를 바꿀 수 없습니다.

결제할 때 쓴 이메일을 넣으면 그 주소로 확인 링크를 보냅니다. 링크를 열고 「키 바꾸기」 를 눌러야 바뀝니다.

요청을 받았습니다. 이 주소로 구매한 기록이 있으면 몇 분 안에 확인 메일이 도착합니다. 24시간 안에 메일의 링크를 여세요. 오지 않으면 스팸함을 확인하세요.

이메일 주소를 확인해 주세요.

지금은 요청을 보내지 못했습니다. 잠시 뒤 다시 시도하거나 support@beakbig.com 으로 문의해 주세요.

바꾸면 이렇게 됩니다

  • 예전 키는 더 쓸 수 없습니다. 예전 키로 등록하려는 Mac 에는 키가 바뀌었다고 알립니다.
  • 등록된 Mac 이 모두 해제됩니다. 계속 쓸 Mac 은 새 키 메일의 링크로 다시 등록하세요.
  • 새 키는 결제할 때 쓴 이메일 주소로만 보냅니다. 이 페이지에는 키를 보여 주지 않습니다.
  • 업데이트 기간과 쓸 수 있는 Mac 수(2대)는 그대로입니다.

알아 두기

  • 등록된 Mac 이 없어도 바꿀 수 있습니다 — Mac 을 바꿨거나 잃어버렸을 때도 됩니다.
  • 키를 잃어버리기만 했다면 바꿀 필요 없이 키 다시 받기 로 같은 키를 받으세요.
  • 두 번째 Mac 부터 새 Mac 이 등록되면 구매 이메일로 알림이 갑니다. 직접 등록한 게 아니라면 그 메일의 링크로 바로 바꿀 수 있습니다.
  • 결제한 이메일을 더 쓸 수 없다면 결제한 날짜와 카드 명세서에 찍힌 내용을 support@beakbig.com 으로 알려 주세요. 확인한 뒤 구매 이메일을 바꿔 드립니다.
