지원

ShouArchive 를 쓰다 막히는 곳이 있으면 알려 주세요. 아래 자주 묻는 질문에 먼저 답이 있을 수 있습니다.

문의 support@shouarchive.beakbig.com 보내시면 접수 확인 메일이 바로 가고, 담당자가 확인한 뒤 하루 안에 답장합니다. 문제 신고 요령은 맨 아래에 있습니다.

시작하기

프로파일은 어디서 읽나요?

Xcode 가 프로비저닝 프로파일을 두는 폴더를 앱이 바로 읽습니다. 따로 허용하거나 설정할 것은 없습니다.

  • ~/Library/Developer/Xcode/UserData/Provisioning Profiles — Xcode 16 이상
  • ~/Library/MobileDevice/Provisioning Profiles — 그 이전 Xcode

다른 곳에 있는 .mobileprovision 파일은 창에 끌어다 놓거나 「파일에서 추가…」로 열어 볼 수 있습니다.

어떤 파일을 지원하나요?
  • 산출물 검사: .ipa (iOS 탭), .apk · .aab (Android 탭)
  • 프로파일: .mobileprovision
  • API 키: App Store Connect 에서 내려받은 .p8

파일은 끌어다 놓거나 「파일 선택…」(⌘O)으로 엽니다.

프로파일 · App Store Connect API

App Store Connect API 키는 어떻게 만드나요?
  1. App Store Connect › 사용자 및 액세스 › 통합 › App Store Connect API 로 갑니다.
  2. 팀 키(Team key)를 만듭니다. 프로파일과 기기를 조회 · 생성하려면 보통 Admin 역할이 필요합니다.
  3. 앱 화면 아래 메뉴의 「API 키」 탭(또는 설정(⌘,) › 「API 키」)에서 「새 키」를 눌러 Issuer ID, Key ID, 내려받은 .p8 파일을 등록합니다. AuthKey_XXXXXXXX.p8 파일을 고르면 Key ID 는 자동으로 채워지고, 팀은 저장할 때 Apple 에서 읽어 옵니다 (못 읽으면 직접 고르도록 알려 줍니다). 붙여 넣을 때 섞인 공백 · 줄바꿈은 저절로 지워집니다.

.p8 파일은 Apple 에서 한 번만 내려받을 수 있으니 안전한 곳에 보관하세요. Apple ID 나 2단계 인증은 쓰지 않습니다.

API 키는 어디에 저장되고, 어디로 전송되나요?

.p8 파일은 고른 자리에 그대로 있고, 앱은 그 파일의 위치(보안 스코프 북마크)만 기억합니다. Apple 에 보내는 요청 토큰은 Mac 에서 서명하며, 키 자체는 Apple 의 App Store Connect API(api.appstoreconnect.apple.com) 말고는 어디로도 가지 않습니다. 앱에서 키를 삭제해도 .p8 파일은 지우지 않습니다.

「곧 만료」와 D-N 배지는 어떤 기준인가요?

만료까지 30일 이내면 「곧 만료」로 분류하고 남은 날짜를 D-N(주황) 배지로 보여 줍니다. 이미 지난 것은 「만료」(빨강)입니다. 「신규」는 최근에 만든 프로파일, 「중복」은 같은 팀 · 같은 앱 ID · 같은 종류의 프로파일이 2개 이상일 때입니다.

「인증서」 카드에는 무엇이 보이나요?

이 Mac 의 키체인에 있는 코드 서명 인증서를 만료된 것까지 함께 보여 줍니다. 프로파일 안에 담긴 인증서는 상세 화면과 비교 화면에서 볼 수 있습니다 (SHA-1 · SHA-256 복사 가능).

기기 등록 한도는 어떻게 되나요?

Apple 개발자 계정은 멤버십 1년마다 기기 종류(iPhone · iPad · Mac …)별로 100대까지 등록할 수 있습니다. 비활성으로 바꾼 기기도 멤버십을 갱신하기 전까지는 자리를 차지합니다. 「프로파일」 › 「프로파일 다운로드」의 「기기」 탭 위쪽에 종류별 사용량(예: iPhone 3 / 100)이 보입니다.

산출물 검사

검사하면 파일이 바뀌거나 어딘가로 올라가나요?

아니요. 파일은 읽기만 합니다. 원본을 고치지 않고, 옆에 결과 파일을 쓰지 않으며, 어떤 서버에도 보내지 않습니다. 검사 결과는 앱 창에만 보입니다.

항목 이름이 무슨 뜻인지 모르겠어요.

점선 밑줄이 있는 항목 이름(권한 · 기기 기능 · 매니페스트 설정 · 인증서 지문 · Entitlements 등)을 누르면 무엇인지 · 자세히 · 주의 설명이 팝오버로 나옵니다. 16 KB 카드는 제목 옆 ⓘ 를 누르세요.

16 KB 페이지 크기 검사는 무엇을 보나요?

Android 15 부터 16 KB 메모리 페이지를 쓰는 기기가 있고, Google Play 는 이를 지원하는 네이티브 라이브러리를 요구합니다. 앱은 64비트(arm64-v8a · x86_64) .so 파일의 ELF LOAD 정렬과, APK 안에 압축 없이 저장된 .so 의 16 KB 경계를 확인해 미지원 라이브러리를 목록으로 보여 줍니다.

OTA 배포

OTA 배포 파일은 ShouArchive 가 올려 두나요?

아니요. ShouArchive 는 IPA · APK 옆 <이름>_OTA 폴더에 설치 페이지(install.html) · manifest.plist · QR 코드를 만들어 줄 뿐, 파일을 올려 두거나 다운로드 링크를 제공하지 않습니다. 폴더를 통째로 직접 운영하는 HTTPS 서버(회사 웹 서버, 클라우드 저장소의 정적 호스팅 등)에 올리고, 앱에 입력한 IPA 주소와 같은 위치가 되게 해 주세요. iOS 는 HTTPS 주소에서만 설치를 시작합니다.

가격 · 라이선스

얼마이고, 무엇이 들어 있나요?

처음 구매는 US$29(세금 별도)이고, 라이선스와 업데이트 1년이 들어 있습니다. 라이선스 키 하나로 Mac 2대에서 씁니다. 프로파일 관리 · API 키 · 산출물 검사 · 히스토리 · 앱 빌드 · 작업 대기열 · 앱 업로드 · 기기 설치 · 다시 서명 · 라이브러리 · IPA 정리 · OTA 배포 · 스토어 배포가 모두 들어 있습니다. 체험 중 · 체험이 끝난 뒤 · 구매 후에 쓸 수 있는 기능은 가격 페이지의 표에 정리해 두었습니다.

언제 나오나요?

가격은 정해졌습니다 — 처음 구매 US$29(업데이트 1년 포함), 그 뒤 업데이트는 1년에 US$15 입니다(세금 별도). 출시일은 아직 정하지 않았습니다. 정해지는 대로 가격 페이지와 다운로드 페이지에 올립니다. 궁금한 점은 support@shouarchive.beakbig.com 으로 보내 주세요.

라이선스 키는 어떻게 등록하나요?

결제가 끝나면 결제 완료 화면과 메일로 키를 받습니다. ShouArchive 가 설치된 Mac 에서 결제 완료 화면의 「ShouArchive 에서 열기」 나 메일의 「앱에서 바로 등록하기」 링크를 누르면 앱이 이 Mac 에 등록할지 묻고, 「등록」 을 누르면 끝입니다. 링크가 열리지 않으면 설정 › 라이선스 › 「키 입력…」 에 결제한 이메일과 키를 넣으세요. 앱에서 결제했다면 그 Mac 에서 「자동 확인」 만 눌러도 됩니다. 결제만으로 Mac 이 등록되지는 않으므로, 다른 Mac 에서 쓰려고 샀다면 그 Mac 에서 등록하면 됩니다.

라이선스 키를 잃어버렸어요

키 다시 받기 에 결제한 이메일 주소를 넣으면 같은 키를 그 주소로 다시 보냅니다. 앱의 설정 › 라이선스 › 「키 다시 받기…」 에서도 됩니다. 키는 결제할 때 쓴 주소로만 보냅니다. 결제할 때 이메일을 잘못 입력했다면 결제한 날짜와 카드 명세서에 찍힌 내용을 support@shouarchive.beakbig.com 으로 알려 주세요.

키가 다른 사람에게 알려진 것 같아요

키 바꾸기 에 결제한 이메일을 넣으면 확인 링크를 보내 드립니다(앱의 설정 › 라이선스 › 「키 바꾸기…」 에서도 됩니다). 링크를 열고 「키 바꾸기」 를 누르면 새 키를 구매 이메일로 보내고, 예전 키는 더 쓸 수 없게 되며 등록된 Mac 은 모두 해제됩니다. 계속 쓸 Mac 은 새 키로 다시 등록하세요. 두 번째 Mac 부터 새 Mac 이 등록될 때마다 구매 이메일로 알림이 가므로, 직접 등록한 게 아니라면 그 메일의 링크로 바로 바꿀 수 있습니다.

다른 Mac 으로 옮기려면?

지금 쓰는 Mac 에서 설정 › 라이선스 의 「해제」를 누르면 자리가 비고, 새 Mac 에서 같은 키로 등록하면 됩니다. 예전 Mac 을 쓸 수 없어 해제하지 못했다면, 새 Mac 에서 등록할 때 자리가 가득 찼다는 창에 등록된 Mac 목록(모델명 · 등록일 · 마지막 사용일)이 나옵니다. 더 쓰지 않는 Mac 을 「해제」 하면 이 Mac 이 바로 등록됩니다(다른 Mac 해제는 30일에 3번까지). 키 하나로 동시에 Mac 2대까지 쓸 수 있습니다.

업데이트 기간이 끝나면 앱을 못 쓰나요?

아니요. 한 번 사면 계속 씁니다. 업데이트 기간 안에 나온 버전은 기간이 끝난 뒤에도 그대로 쓸 수 있습니다. 기간이 끝난 뒤에 나온 버전만 업데이트를 갱신(1년에 US$15)해야 설치됩니다. 갱신은 자동으로 이루어지고(7일 전에 결제 이메일과 앱에서 알립니다) Paddle 결제 안내 메일의 관리 링크나 설정 › 라이선스 › 「결제 관리…」 에서 언제든 끌 수 있으며, 기간이 끝난 뒤에 다시 갱신하면 그 결제일부터 새로 1년이 시작됩니다.

체험이 끝나면?

14일 체험은 결제 수단 없이 시작하므로 끝나도 자동으로 결제되지 않습니다. 라이선스 키 없이 체험이 끝나면 프로파일 관리(다운로드 · 만들기 · 기기 등록 포함) · 산출물 검사 · API 키 관리 · 히스토리(기록 보기)는 계속 쓸 수 있고, 앱 빌드 · 작업 대기열 · 앱 업로드 · 기기 설치 · 다시 서명 · 라이브러리 · IPA 정리 · OTA 배포 · 스토어 배포는 구매한 뒤 설정 › 라이선스 에 키를 넣으면 다시 열립니다.

환불은 어떻게 받나요?

처음 구매와 업데이트 갱신 모두 결제 후 14일 안이면 전액 환불합니다. support@shouarchive.beakbig.com 으로 결제 이메일과 주문 번호(Paddle 영수증에 있음)를 보내 주시면 판매자가 Paddle 에 바로 환불을 요청합니다 — 가장 빠른 방법입니다. Paddle 영수증 메일의 링크나 paddle.net 에서 직접 요청할 수도 있습니다. 앱의 설정 › 라이선스 › 「해지 방법…」 에도 같은 안내가 있습니다. 자세한 기준은 환불 정책에 있습니다.

내 개인정보를 지우고 싶어요

개인정보 삭제 페이지에 결제한 이메일을 넣으면 확인 메일을 보냅니다. 메일의 링크에서 「삭제」 를 누르면 그 이메일의 모든 라이선스가 해지되고 등록된 Mac 이 해제되며, 구매 이메일 · 키 · 발송 기록이 지워집니다. 되돌릴 수 없고 키를 다시 받을 수도 없습니다. 결제 기록(거래 id · 종류 · 시각)은 법에 따라 5년 보관하고, Paddle 이 가진 결제 정보는 Paddle 에 따로 요청합니다. 자세한 내용은 개인정보 처리방침 11항에 있습니다.

일반

표시 언어를 바꾸려면?

툴바의 지구본 메뉴에서 언어를 고르고 「지금 다시 시작」을 누르면 그 언어로 다시 열립니다. 언어는 앱을 다시 시작해야 적용되며, 하던 작업은 그대로 남습니다. 한국어 · English · 日本語 · 简体中文 · 繁體中文 · Español 을 지원합니다.

테마와 글자 크기는?

툴바의 테마 메뉴에서 색 테마(Black & White · ShouArchive)와 라이트 · 다크 · 시스템 설정을 고릅니다. 글자 크기는 보기 메뉴의 「텍스트 크게 ⌘+ · 작게 ⌘- · 기본 크기 ⌘0」 또는 설정(⌘,) › 화면에서 85 % ~ 150 % 사이로 바꿉니다.

시스템 요구 사항

macOS 15 Sequoia 이상. Apple Silicon 과 Intel Mac 모두 지원합니다. 프로파일 다운로드 · 생성 · 기기 등록에는 App Store Connect API 키가 필요하고, 라이선스 확인 · 업데이트 확인 · 앱 업로드 · 스토어 배포에는 인터넷 연결이 필요합니다. 산출물 검사와 설치된 프로파일 보기는 인터넷 없이 동작합니다.

문제를 신고하려면?

support@shouarchive.beakbig.com 으로 아래 내용을 함께 보내 주시면 빨리 살펴볼 수 있습니다.

앱 안에서는 도움말 메뉴 › 「문의 · 제안 보내기…」(또는 설정(⌘,) › 「메일 작성…」)로 바로 쓸 수 있습니다. 앱 버전 · macOS 정보는 본문 아래에 자동으로 붙습니다.

  • macOS 버전 (Apple 메뉴 › 이 Mac에 관하여)
  • 앱 버전 (ShouArchive 메뉴 › ShouArchive 정보)
  • 어떤 순서로 무엇을 했을 때 무슨 일이 생겼는지
  • 가능하면 화면 캡처나 오류 문구

IPA · APK · 프로파일 파일은 보내지 않아도 됩니다. 꼭 필요하면 따로 요청드리며, 보내실 때는 키 파일(.p8)이나 민감한 정보가 들어 있지 않은지 확인해 주세요.
