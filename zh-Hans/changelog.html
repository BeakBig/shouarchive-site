更新日志

ShouArchive 各版本的更新记录

1.0.6 — 2026年10月31日

新增

  • 应用构建 — 未安装 Xcode 时，打开 iOS 的应用构建页面会在窗口中央显示提示。“前往 App Store”会打开 App Store 中的 Xcode 页面，“关闭”会回到上一个页面
  • 应用构建 — 缺少 Android SDK 或 JDK 时也会显示同样的提示。“前往下载页面”会打开 Android Studio 下载页面；如果已安装 Android Studio，按钮会变为“打开 Android Studio”
  • 应用构建 — 构建页面顶部的提示和失败的任务中也新增了“从 App Store 获取 Xcode”“获取 Android Studio”按钮。安装后回到 ShouArchive，提示就会消失

变更

  • API 密钥 — 用“导出备份”保存后，会在访达中选中显示保存的文件

修复

  • 应用构建 — 未安装 Xcode 时，iOS 构建、上传、安装到设备等操作会直接显示 Apple 的英文错误，现在改为“此操作需要 Xcode”的提示，也不再弹出 macOS 的开发者工具安装窗口
  • 应用构建 — 修复了已安装 Xcode 但 xcode-select 指向 Command Line Tools 时 iOS 操作失败的问题。现在会自动找到并使用已安装的 Xcode

1.0.5 — 2026年10月31日

变更

  • API 密钥 — iOS 密钥的 .p8 内容现在保存在 macOS 钥匙串中。删除或移动原 .p8 文件后仍可继续使用；已添加的密钥只要原文件还在，启动时也会移入钥匙串
  • API 密钥 — iOS 密钥也新增了“导出备份”，可将钥匙串中保存的 .p8 存为 AuthKey_<Key ID>.p8 文件
  • 许可证 — 打开这台 Mac 正在使用的密钥的链接时，只会提示“此许可证已在这台 Mac 上注册”
  • 许可证 — 换成另一个许可证的密钥时，会释放这台 Mac 在之前许可证中的席位
  • 许可证 — 已撤销的许可证在 设置 › 许可证 中显示为购买前的样子（只保留状态、原因和密钥）

修复

  • 许可证 — 通过链接注册密钥失败时，错误不再与警告重复显示两次
  • API 密钥 — 修复了“导出备份”因未创建新文件夹而无法保存的问题
  • 确认窗口 — 修复了部分确认窗口（密钥备份、删除密钥、创建封闭测试轨道）中出现两个“取消”按钮的问题

1.0.4 — 2026年10月30日

修复

  • 窗口大小 — 用底部标签栏或子菜单切换界面时，如果窗口自行纵向变长，会恢复到之前的高度
  • macOS 26 — 工具栏加上了背景，窗口标题不再压在左栏的分隔线上
  • 描述文件 — 修正了英文界面中证书到期日前缺少空格的问题

1.0.3 — 2026年10月29日

变更

  • 资讯 — 移到左上角 iOS / Android 旁边（不再位于底部标签栏），可在其中选择 iOS、Android 或 ShouArchive
  • 更新记录 — 资讯 › ShouArchive 列出每个版本的变更；有新版本时显示“新版本”和“检查更新…”

1.0.2 — 2026年10月29日

变更

  • 资讯 — “查看原文”会打开应用语言的译文页面（没有译文时打开英文原文）
  • API 密钥 — 保存或删除密钥的结果会在屏幕顶部短暂显示

1.0.1 — 2026年10月29日

新增

  • 资讯 — 汇集 Apple 和 Google 审核与政策资讯的新标签页（位于底部标签栏末尾，带未读标记）。可在 设置 › 通用 中关闭自动获取

1.0.0 — 首次发布

功能

  • 描述文件管理 — 已安装的描述文件 · 到期徽章 · 筛选 · 两个比较
  • 描述文件下载 · 创建 · 续期 · 设备注册（App Store Connect API 密钥）
  • 产物检查 — IPA · APK · AAB，签名 · 权限 · 安全设置
  • 历史记录 — 描述文件 · 构建 · 分发的操作记录
  • 应用构建 · 任务队列 — 直接构建 IPA · APK，多个任务排队执行
  • 上传应用 — 上传到 TestFlight · Play Console
  • 设备安装 — 设备列表 · 安装 · 重新安装
  • 重新签名 · 库 · IPA 整理 — 用其他描述文件重新签名、保管产物、整理 IPA
  • OTA 分发 — 生成用于分发的安装包
  • 商店分发（iOS · Android）— 商店信息 · 截图 · 提交审核 · 回复评论
