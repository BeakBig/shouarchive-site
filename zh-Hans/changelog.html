更新日志

ShouArchive 各版本的更新记录

1.2.0 — 2026年11月13日

新增

  • 新主题「海报」 — 通过带编号的栏目栏在各画面之间切换，并在首屏「今天」一眼看到需要留意的事项。按 ⌘K「前往何处」可直接跳到想去的画面。若从未选过主题，应用会以「海报」打开，可在窗口右上角的主题菜单中更改
  • 工作流 — 把项目、编译、签名、创建安装文件、检查和上传用节点串起来一次执行。可放置多个签名分支，同时生成 Development、Ad Hoc 和 App Store。「应用构建」标签页已由工作流取代。上传到 Google Play 正式版轨道时，运行前总会先确认
  • Mac 应用直接分发 — 在工作流中选择签名方式「Direct Distribution (Mac)」，即可完成 Developer ID 签名、公证并生成 DMG
  • 自动创建描述文件 — 有 App Store Connect API 密钥但没有匹配的描述文件时，会在构建过程中创建并安装。也可以通过签名栏中的「创建描述文件…」提前创建。只使用这台 Mac 上已有的证书，不会新建证书或 App ID
  • 仪表盘 — 把需要留意的事项、工作流、日程、iOS、Android 和资讯汇集到一个画面
  • 记录 › 时间线 · 计划 — 记录开发笔记，安排工作流在指定日期运行，并提醒重叠的日程。可导出为日历文件（.ics）
  • 刘海处的构建进度 — 构建时在屏幕顶部中央显示应用名称和当前步骤（设置 › 通用「在刘海处显示构建进度」）
  • 同时构建 — 构建队列可同时运行 iOS 与 Android 合计 2～3 个构建
  • 月度订阅 — 可以登记并使用月度订阅（每月 US$3 · 4 台 Mac）的密钥。在设置 › 许可证中查看状态和下次付款日期，并通过「管理付款…」取消订阅或更换付款方式。2026年12月31日前可在价格页面提前订阅（前 3 次付款各 US$2，下次付款日为 2027年2月1日）
  • 加购许可证 — 想在更多 Mac 上使用时，可通过设置 › 许可证中的「加购许可证…」购买新密钥
  • App Store 截图新方式 — 通过 App Store Connect 的新截图方式（App Asset Library）读取、上传、排序和删除截图，并支持 iPhone Duo 尺寸
  • Google Play — 可为图片加上「AI 生成的图片」标记，并显示每个轨道的审核与发布阶段
  • 网络连接检查 — 需要联网的画面在断网时显示「网络连接已断开」，恢复连接后会重新加载。上传不再长时间等待，而是立即提示失败
  • 使用统计 — 每天发送一次无法识别个人身份的使用统计（当天是否打开、打开的画面和各功能的使用次数）（隐私政策第 5 条）

变更

  • 管理描述文件 — 导出和按团队查看已适配新画面；选中多个时，可在列表上方的一行栏中导出或删除
  • 首次发布 — 尚无已发布版本的应用不再要求填写「此版本的新功能」
  • 清理 — 也会删除构建留下的系统数据

修复

  • 输入速度 — 修复了输入商店信息等内容时每输入一个字都会变慢的问题
  • 取消构建 — 修复了取消构建后不能立即停止的问题
  • 翻译 — 修复了在其他语言中部分文字显示为韩语的问题

1.1.4 — 2026年11月10日

修复

  • 管理描述文件的速度 — 描述文件较多时，在“管理描述文件”中选择列表项或导出时每次都会短暂卡顿的问题已修复（1.1.3 中出现）

1.1.3 — 2026年11月10日

新增

  • 导出描述文件 — 现在可以在“管理描述文件”中导出描述文件。单个描述文件保存为原文件，多个则打包成一个 zip 文件。可使用每个描述文件上的“导出…”按钮，或选中多个后使用列表上方的导出按钮或右键菜单
  • 按团队查看 · 导出 — 有两个以上团队时，在“团队”中选择“全部”，列表会按团队分开显示，并可将每个团队的描述文件导出为 zip。一次导出多个团队时，zip 内按团队分文件夹。团队和全部导出只包含列表中显示的描述文件（按状态、类型和搜索筛选后的结果）

1.1.2 — 2026年11月5日

新增

  • 新版本提醒 — 有新版本时，会在主窗口右下角用一行提示，例如“有新版本。v1.1.3”。点击后可在 资讯 › ShouArchive 中查看变更并“更新”

修复

  • 产物检查 — 修复了应用语言为简体中文、繁體中文或 Español 时，在 Android 结果中打开“构建 · 配置”会导致应用退出的问题
  • 产物检查 — Android 的“检查记录”现在也会保存包名和 versionCode

1.1.1 — 2026年11月4日

新增

  • 产物检查 — 新增“检查记录”：已检查的安装文件（文件、应用名称、版本、结果；iOS 还包括 Bundle ID 和签名）会累积保存，每条都可添加备注。点击“打开已生成的文件”左侧的按钮打开
  • 应用构建 — 将 iOS 构建所用的 Swift 编译设置（SWIFT_ACTIVE_COMPILATION_CONDITIONS、OTHER_SWIFT_FLAGS、优化级别等）记录在历史记录中。用产物检查打开该 IPA 时，会在“配置”中显示（这些值不会保留在 IPA 中，因此只有用 ShouArchive 构建的 IPA 才会显示）

变更

  • Android — 底部菜单中的产物检查已与 iOS 一样移到“构建”中

1.1.0 — 2026年11月3日

新增

  • AI 集成 — 将 ShouArchive 连接到 Claude Code、Claude 桌面版、Cursor、Codex 等支持 MCP 的 AI 工具后，就可以用自然语言询问这台 Mac 上的描述文件、产物检查结果和 App Store Connect 的进展。在左上角的“AI”界面或 设置 › AI 集成 中开启“允许 AI 工具连接”（默认关闭）
  • AI 界面 — 主窗口左上角的“AI”把 AI 集成汇集到了一个界面。在“安装到 AI 工具”中点按“安装”，就会把 ShouArchive 写入 Claude Code、Claude 桌面版、Codex、Cursor、Gemini CLI、VS Code、Windsurf 的设置（更改前会备份原文件）。开启开关、每个工具的批准方式和最近的执行请求也在这里查看
  • AI 集成 — 重新创建描述文件、App Store 文案、截图、关联构建、提交审核，以及 Google Play 文案、图片、轨道发布等执行请求，需先开启“允许执行请求”，之后只会执行你在 ShouArchive 批准窗口中逐条请求批准的内容，并记录下来。每个工具都可以选择“批准后执行”“无需批准即执行”或“不使用”
  • AI 集成 — 在“当前连接”中可以查看已连接的 AI 工具和等待批准的请求。App Store Connect、Google Play 的密钥仍保存在这台 Mac 上，交给 AI 工具的只有该工具所调用功能的结果
  • 菜单栏 — 菜单栏图标旁会显示等待批准的请求、构建阶段和 7 天内到期的描述文件（D-N）；在面板中可以查看构建进度、30 天内到期的描述文件，复制最近的 OTA 链接，并查看 AI 集成状态。可在 设置 › 通用 中关闭
  • 设置 — 设置中新增“致谢”标签页，可查看 Android 机器人图像的来源以及应用所含开源软件（Sparkle、Lottie）的许可全文

变更

  • 更新 — 开启“自动检查更新”后，启动应用时也会检查一次（以前要距上次检查满一天才会检查）

1.0.7 — 2026年11月1日

修复

  • 应用构建 — 在缺少工具的提示中，点按“前往 App Store”“前往下载页面”“打开 Android Studio”后，会在打开获取页面后像“关闭”一样回到上一个页面

1.0.6 — 2026年10月31日

新增

  • 应用构建 — 未安装 Xcode 时，打开 iOS 的应用构建页面会在窗口中央显示提示。“前往 App Store”会打开 App Store 中的 Xcode 页面，“关闭”会回到上一个页面
  • 应用构建 — 缺少 Android SDK 或 JDK 时也会显示同样的提示。“前往下载页面”会打开 Android Studio 下载页面；如果已安装 Android Studio，按钮会变为“打开 Android Studio”
  • 应用构建 — 构建页面顶部的提示和失败的任务中也新增了“从 App Store 获取 Xcode”“获取 Android Studio”按钮。安装后回到 ShouArchive，提示就会消失

变更

  • API 密钥 — 用“导出备份”保存后，会在访达中选中显示保存的文件

修复

  • 应用构建 — 未安装 Xcode 时，iOS 构建、上传、安装到设备等操作会直接显示 Apple 的英文错误，现在改为“此操作需要 Xcode”的提示，也不再弹出 macOS 的开发者工具安装窗口
  • 应用构建 — 修复了已安装 Xcode 但 xcode-select 指向 Command Line Tools 时 iOS 操作失败的问题。现在会自动找到并使用已安装的 Xcode

1.0.5 — 2026年10月31日

变更

  • API 密钥 — iOS 密钥的 .p8 内容现在保存在 macOS 钥匙串中。删除或移动原 .p8 文件后仍可继续使用；已添加的密钥只要原文件还在，启动时也会移入钥匙串
  • API 密钥 — iOS 密钥也新增了“导出备份”，可将钥匙串中保存的 .p8 存为 AuthKey_<Key ID>.p8 文件
  • 许可证 — 打开这台 Mac 正在使用的密钥的链接时，只会提示“此许可证已在这台 Mac 上注册”
  • 许可证 — 换成另一个许可证的密钥时，会释放这台 Mac 在之前许可证中的席位
  • 许可证 — 已撤销的许可证在 设置 › 许可证 中显示为购买前的样子（只保留状态、原因和密钥）

修复

  • 许可证 — 通过链接注册密钥失败时，错误不再与警告重复显示两次
  • API 密钥 — 修复了“导出备份”因未创建新文件夹而无法保存的问题
  • 确认窗口 — 修复了部分确认窗口（密钥备份、删除密钥、创建封闭测试轨道）中出现两个“取消”按钮的问题

1.0.4 — 2026年10月30日

修复

  • 窗口大小 — 用底部标签栏或子菜单切换界面时，如果窗口自行纵向变长，会恢复到之前的高度
  • macOS 26 — 工具栏加上了背景，窗口标题不再压在左栏的分隔线上
  • 描述文件 — 修正了英文界面中证书到期日前缺少空格的问题

1.0.3 — 2026年10月29日

变更

  • 资讯 — 移到左上角 iOS / Android 旁边（不再位于底部标签栏），可在其中选择 iOS、Android 或 ShouArchive
  • 更新记录 — 资讯 › ShouArchive 列出每个版本的变更；有新版本时显示“新版本”和“检查更新…”

1.0.2 — 2026年10月29日

变更

  • 资讯 — “查看原文”会打开应用语言的译文页面（没有译文时打开英文原文）
  • API 密钥 — 保存或删除密钥的结果会在屏幕顶部短暂显示

1.0.1 — 2026年10月29日

新增

  • 资讯 — 汇集 Apple 和 Google 审核与政策资讯的新标签页（位于底部标签栏末尾，带未读标记）。可在 设置 › 通用 中关闭自动获取

1.0.0 — 首次发布
