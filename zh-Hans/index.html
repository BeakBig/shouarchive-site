描述文件

描述文件：从到期日期到设备注册，一站管理

一眼看清 Xcode 安装的所有描述文件。添加 App Store Connect API 密钥后，下载、创建、续期描述文件都无需离开应用。

已安装的描述文件

  • 每一行都有 D-N 到期徽章——30 天内显示橙色，过期后显示红色
  • 筛选：全部 · 新增 · 重复 / 有效 · 即将过期 · 到期
  • 详情视图：设备 UDID、内嵌证书（SHA-1 · SHA-256）和 Entitlements，均可复制
  • 并排比较两个描述文件——列出有差异的设备、证书和 Entitlements
  • 拖入 .mobileprovision 文件即可添加；多选可批量删除

App Store Connect API

  • 获取团队的描述文件，只安装缺少的那些
  • 列出已注册设备并注册新设备，按类型显示配额（例如 iPhone 3 / 100）
  • 创建描述文件：类型、平台、Bundle ID、证书、设备
  • 设备变动或临近到期时，重新生成或续期

只需 Issuer ID、Key ID 和 .p8 文件。密钥保存在你的 Mac 上，请求令牌在本地签名。

历史记录

  • 下载、创建、重新生成、设备注册、添加与删除，按日期分组
  • 按名称、Bundle ID、UUID 或 UDID 搜索
  • 需要追溯什么时候改了什么时，非常方便

产物检查

上传之前，先打开 IPA、APK 或 AAB 看一看

拖入文件即刻解析，无需任何外部工具。从商店页面信息到签名、权限和安全设置，每一项都附有通俗易懂的说明。

商店显示信息

可以直接从构建产物中读出的产品页面信息。

  • 图标、名称、提供者、大小、支持的语言
  • iOS：类别、兼容性、App Tracking Transparency 提示、隐私清单摘要
  • Android：下载大小、所需 Android 版本、权限数量、应用内结算、广告 ID、支持的设备

iOS 签名与权限

  • 签名、描述文件与 Entitlements
  • 权限用途说明（…UsageDescription）——为空时会给出警告
  • 框架、应用扩展和 Entitlements 列表完整显示，绝不截断

Android 签名、安全与 16 KB

  • 证书指纹 SHA-256 · SHA-1 · MD5，以及用于 Kakao 和 Facebook 的密钥哈希
  • 权限分类与设备功能
  • 清单安全设置：allowBackup、明文 HTTP、导出的组件、深层链接
  • 原生库的 16 KB 页面大小对齐检查
  • 构建、配置与大小明细（DEX、资源、各 ABI 的原生库）

只读。文件不会被修改，不会在它旁边写入任何内容，也不会上传到任何地方。
