隐私政策

ShouArchive (macOS) · 生效日期 2026年10月29日 · 开发者 · 销售者 Beakbig

摘要。应用没有分析工具 · 跟踪 · 广告 · 账户。本网站只使用不用 Cookie 的访问统计（Cloudflare Web Analytics — 不识别个人的汇总数据）（第 6 项）。检查的文件只在 Mac 上读取。App Store Connect · Google Play 功能使用你亲自登记的密钥直接连接 Apple · Google。发送给销售者的只有验证许可证时的许可证密钥 · 设备标识值 · Mac 型号 · 应用版本、注册、重新获取、更换密钥或删除记录时的购买邮箱地址（第 5 项）、作为记录商户处理支付的 Paddle 转交的购买信息（第 7 项），以及您通过咨询邮件直接发来的内容（第 14 项）。

1. 不收集的信息

应用不会做以下任何事情。

  • 不收集使用统计 · 错误报告等分析（analytics）数据。
  • 不跟踪用户或设备，也不展示广告。
  • 没有账户或登录。许可证凭一个密钥验证。
  • 不会把检查的文件内容、项目源代码、构建产物发送给销售者。

2. 文件处理

产物检查和描述文件管理所处理的文件（IPA · APK · AAB · .mobileprovision）只在你的 Mac 上读取。文件内容以及由此得出的信息（Bundle ID · 签名证书 · 权限列表等）只显示在应用窗口中，不会传输到任何地方。产物检查不会修改原文件。通过构建 · 导出生成的文件只保存在你选择的文件夹中。

3. 网络使用

应用只在以下情况下连接网络。发往 Apple · Google 的请求不经过销售者的服务器，直接从你的 Mac 发出。

4. 保存在 Mac 上的数据

  • 应用设置（主题 · 语言 · 文本大小 · 项目列表等）保存在 macOS 的用户偏好设置 · 应用支持文件夹中。
  • API 密钥正文保存在这台 Mac 的钥匙串中，不会通过 iCloud 钥匙串同步。以文件形式选择的密钥只记住该文件的位置。
  • 描述文件活动记录 · 构建记录只保存在本地，可以在应用中删除。
  • “资讯”标签页获取的资讯列表和已读记录只保存在这台 Mac 上。
  • 许可证密钥和验证结果保存在这台 Mac 上。许可证服务器上保存的内容见第 5 项。
  • .p8 文件和构建产物等你自己放置的文件，应用不会删除。

5. 许可证验证 — 发送的信息

应用仅为注册和验证许可证以及确认更新期，将下列值发送到许可证服务器，不作其他用途，所有传输均通过 HTTPS 进行。网站的重新获取密钥 · 更换密钥 · 删除个人信息页面和付款完成页面也只发送下面列出的值。

发送的值内容为什么需要
许可证密钥用于识别所购许可证的密钥确认许可证是否有效，以及更新期截至何时
购买邮箱地址付款时使用的邮箱地址。仅在密钥输入窗口中注册时和申请重新获取密钥时发送确认输入的密钥属于该笔购买，并且只将密钥重新发送到购买时的邮箱

应用版本应用版本 · 构建号确认该版本是否在更新期内发布，并解决问题
访问记录时间、操作（激活 · 验证 · 解除等）、结果、许可证 id、设备标识值的哈希、应用版本、简短原因。不含 IP 地址。30 天后自动删除应对故障并解决问题

何时发送什么。

  • 激活 — 许可证密钥、购买邮箱地址（在密钥输入窗口中注册时）、设备标识值、安装标识值、Mac 型号、应用版本
  • 许可证验证 — 大约每 12 小时发送许可证密钥（如有）、设备标识值、安装标识值、Mac 型号、应用版本
  • 免费期查询 — 大约每 12 小时一次（即使没有许可证）。不发送任何值，只有包含应用名称和版本的 User-Agent，服务器也不记录这些请求
  • 注册付款的 Mac（在应用内付款后，于确认窗口中选择“注册此 Mac”） — 设备标识值、安装标识值、Mac 型号、应用版本
  • 已注册 Mac 列表 · 解除其他 Mac — 许可证密钥、设备标识值、安装标识值、要解除的 Mac 在列表中的 id
  • 解除 — 许可证密钥（应用中有时）、设备标识值、应用版本
  • 开始支付（购买 · 续订） — 许可证密钥（续订时）、设备标识值、安装标识值、应用版本、语言（购买时）。支付本身在 Paddle 的付款页面完成
  • 管理付款链接（设置 › 许可证 › “管理付款…”） — 许可证密钥（如有）、设备标识值、安装标识值、应用版本。收到的链接不会保存在应用中
  • 重新获取密钥（应用 · 网站） — 购买邮箱地址、语言
  • 更换密钥（应用 · 网站） — 申请确认邮件时为购买邮箱地址、语言；通过邮件中的链接更换时为确认值、语言
  • 删除个人信息（网站） — 申请确认邮件时为购买邮箱地址、语言；通过邮件中的链接删除时为确认值、语言
  • 在网站购买 · 付款完成页面 — 开始购买时发送语言；付款后发送交易 id 和付款确认值，仅用于在该页面显示刚购买的许可证密钥

服务器上保存的内容。设备 · 安装标识值不保存原文，只保存哈希值（SHA-256 · HMAC-SHA256）。许可证密钥除用于查询的哈希值外，还保存加密（AES-256-GCM）后的值，以便将同一密钥重新发送给您；解密密钥与数据库分开保存在服务器的机密设置中，仅凭数据库无法得知许可证密钥。付款确认值以及申请重新获取或更换密钥时使用的邮箱地址只保存哈希值。更换密钥的确认链接值和更换前的密钥也只保存哈希值；更换前的密钥用于告知使用它发来的请求密钥已更换。Mac 型号、应用版本和购买邮箱地址按原样保存，购买邮箱地址用于查询许可证和发送密钥。从 Paddle 接收客户 · 交易 · 自动续订 id、自动续订状态（开启 · 关闭）、价格 id 以及更新期的结束日期。不接收姓名 · 地址 · 卡片信息。

不保存的内容。IP 地址、请求头和请求正文、姓名 · 地址、卡号、营销同意、使用统计。应用不发送 macOS 版本。

  • 可用于识别用户身份的值（用户名 · 直接为设备设定的名称等）不用于许可证验证。
  • 文件（IPA · APK · AAB · .mobileprovision）的内容和产物检查结果不会发送到许可证服务器。
  • 应用中不加入广告 · 跟踪 · 行为分析 SDK。

  • 服务器使用 Cloudflare, Inc.（美国公司）的 Workers，在离用户较近的 Cloudflare 数据中心运行，数据库位于亚太地区（该地区内的实际位置由 Cloudflare 决定）。许可证服务器和本网站由 Cloudflare 出于传输 · 安全目的处理；销售者已关闭 Cloudflare 的请求日志，不保存 IP 地址。本网站使用 Cloudflare Web Analytics 进行访问统计——不使用 Cookie · 本地存储 · 设备标识值，只保留页面地址 · 来源 · 浏览器 · 国家等汇总数据，销售者无法查看每位访问者的记录。支付由 Paddle 作为记录商户处理（第 7 项）。

  • 销售者与 Paddle 各自都是这些数据的独立数据管理主体。销售者仅将收到的信息用于签发许可证、核对支付和回应客户咨询，不作其他用途。

9. 共享与出售

销售者共享个人信息的对象只有第 6 项所述的许可证服务器（Cloudflare）· 密钥发送服务（Resend）和第 7 项所述的 Paddle，不会出售或交给其他第三方。第 3 项所述与 Apple · Google 的通信是应你的请求、使用你自己的账户和密钥进行的。应用安装文件（DMG）从 Cloudflare R2 下载，卖家不会另外收集下载记录。

10. 儿童

ShouArchive 是面向软件开发者的工具，不面向儿童。我们不会在知情的情况下收集未满 14 周岁者的个人信息。

11. 数据主体的权利

使用者对个人信息享有查阅 · 更正 · 删除 · 限制处理 · 拒绝提供（据此停止处理）的权利。

  • 可以拒绝的部分 — 许可证验证是使用所购许可证所必需的处理。拒绝后将无法使用由许可证开启的功能。
  • 法定代理人或代理人提出请求时，会先确认授权关系后再处理。

本政策以大韩民国个人信息保护法为依据编写。对于 EU · EEA 和英国的用户，我们同样保障 GDPR 与 UK GDPR 所规定的权利。

12. 跨境传输

  • 接收方与国家 — 许可证记录由 Cloudflare, Inc.（美国）处理，支付信息由 Paddle（英国 · 美国，第 7 项）处理，密钥发送邮件由 Resend, Inc.（美国）处理。安装文件的下载经由 Cloudflare R2（Cloudflare, Inc.，美国），网站访问统计也由 Cloudflare 处理。
  • 保存位置 — 许可证记录保存在亚太地区的数据库（Cloudflare D1）中，请求在离用户较近的 Cloudflare 数据中心处理。
  • 何时 · 如何 — 在激活 · 许可证验证 · 查看已注册 Mac 列表 · 重新获取密钥 · 更换密钥 · 删除个人信息 · 开始支付（购买 · 续订）· 请求管理付款链接时，以及发送第 6 项所列邮件时，通过网络发送。
  • 项目 · 目的 · 保存期限 — 与第 5 项和第 6 项所列相同。
  • 保护措施 — Cloudflare 遵守数据处理条款（含 EU 标准合同条款），Paddle 作为记录商户按其自身的隐私政策处理支付信息。
  • 拒绝方式与结果 — 不使用许可证时不会发生跨境传输。此时试用期结束后只能使用描述文件管理 · 产物检查 · API 密钥管理 · 历史记录查看。
