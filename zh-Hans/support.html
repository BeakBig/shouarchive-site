快速上手

描述文件是从哪里读取的？

应用会直接读取 Xcode 存放描述文件的文件夹，无需另外授权或设置。

  • ~/Library/Developer/Xcode/UserData/Provisioning Profiles — Xcode 16 及更高版本
  • ~/Library/MobileDevice/Provisioning Profiles — 较早的 Xcode 版本

存放在其他位置的 .mobileprovision 文件，可以拖入窗口，或通过「从文件添加…」打开查看。

支持哪些文件类型？
  • 产物检查：.ipa（iOS 标签页）、.apk · .aab（Android 标签页）
  • 描述文件：.mobileprovision
  • API 密钥：从 App Store Connect 下载的 .p8

将文件拖到窗口上，或使用「选择文件…」（⌘O）打开。

描述文件 · App Store Connect API

如何创建 App Store Connect API 密钥？
  1. 前往 App Store Connect › 用户和访问 › 集成 › App Store Connect API。
  2. 生成一个团队密钥（Team key）。读取和创建描述文件与设备通常需要管理（Admin）角色。
  3. 在应用底部菜单的「API 密钥」标签页（或设置（⌘,）›「API 密钥」）中点按「新密钥」，登记 Issuer ID、Key ID 和下载的 .p8 文件。选择 AuthKey_XXXXXXXX.p8 文件时会自动填入 Key ID，保存时会从 Apple 读取团队（读取不到时会提示你自行选择）。粘贴时夹带的空格和换行会被自动去除。

Apple 只允许下载一次 .p8 文件，请妥善保管。应用不会使用 Apple ID 或双重认证。

API 密钥保存在哪里？会发送到哪里？

.p8 文件留在你选择的位置，应用只记住该文件的位置（安全作用域书签）。发送给 Apple 的请求令牌在 Mac 上签名，密钥本身除了 Apple 的 App Store Connect API（api.appstoreconnect.apple.com）之外不会发送到任何地方。在应用中删除密钥不会删除 .p8 文件。

「即将过期」和 D-N 徽章的标准是什么？

距离到期30 天以内的会归为「即将过期」，并以 D-N（橙色）徽章显示剩余天数。已经过期的则为「到期」（红色）。「新增」表示最近创建的描述文件；「重复」表示同一团队、同一 App ID、同一类型的描述文件有 2 个或以上。

「证书」卡片中显示什么？

显示这台 Mac 钥匙串中的代码签名证书，包括已过期的证书。描述文件中内嵌的证书可在详情视图和比较视图中查看（可复制 SHA-1 · SHA-256）。

设备注册上限是多少？

Apple 开发者账户在每个会员年度内，每种设备类型（iPhone · iPad · Mac……）最多可注册 100 台。设为停用的设备在会员资格续期之前仍会占用名额。「描述文件」›「下载描述文件」中「设备」标签页的上方会显示各类型的用量（例如 iPhone 3 / 100）。

产物检查

检查会修改文件或把它上传到某处吗？

不会。文件只会被读取。原文件不会被修改，不会在旁边写入结果文件，也不会发送到任何服务器。检查结果只显示在应用窗口中。

我不明白项目名称是什么意思。

点击带虚线下划线的项目名称（权限 · 设备功能 · 清单设置 · 证书指纹 · Entitlements 等），会以弹出框显示是什么 · 详情 · 注意事项说明。16 KB 卡片请点击标题旁的 ⓘ。

16 KB 页面大小检查看的是什么？

从 Android 15 开始，部分设备使用 16 KB 内存页，Google Play 要求原生库对此提供支持。应用会检查 64 位（arm64-v8a · x86_64）.so 文件的 ELF LOAD 对齐，以及 APK 中以未压缩方式存储的 .so 的 16 KB 边界，并列出不支持的库。

OTA 分发

ShouArchive 会托管 OTA 安装文件吗?

不会。ShouArchive 在 IPA · APK 旁边的 <名称>_OTA 文件夹中生成安装页面(install.html)、manifest.plist 和二维码,只负责生成这些文件,不托管文件,也不提供下载链接。请把整个文件夹上传到您自己运营的 HTTPS 服务器(公司 Web 服务器、云存储的静态托管等),并让位置与在应用中填写的 IPA 地址一致。iOS 只会从 HTTPS 地址开始安装。

如何注册许可证密钥？

付款完成后，您会在付款完成页面和邮件中收到密钥。在已安装 ShouArchive 的 Mac 上，点按付款完成页面上的“在 ShouArchive 中打开”或邮件中的“在应用中直接注册”链接，应用会询问是否在此 Mac 上注册，点按“注册”即可完成。如果链接无法打开应用，请在“设置 › 许可证 › 输入密钥…”中输入付款邮箱和密钥。如果是在应用内付款的，也可以在那台 Mac 上点按“自动检查”。仅付款并不会注册 Mac，如果是为另一台 Mac 购买的，请在那台 Mac 上注册。

许可证密钥丢失了怎么办？

在重新获取密钥页面输入付款时使用的邮箱，我们会将同一密钥重新发送到该邮箱。也可以在应用的“设置 › 许可证 › 重新获取密钥…”中申请。密钥只会发送到购买时使用的邮箱。如果付款时邮箱输入有误，请将付款日期和银行卡账单上显示的内容发送至 support@shouarchive.beakbig.com。

我的许可证密钥可能已被他人知道

在更换密钥页面输入付款时使用的邮箱，我们会发送确认链接（也可以在应用的“设置 › 许可证 › 更换密钥…”中申请）。打开链接并点按“更换密钥”后，新密钥会发送到购买邮箱，旧密钥将无法使用，所有已注册的 Mac 都会被停用。请用新密钥重新注册要继续使用的 Mac。从第二台 Mac 起，每当有新的 Mac 注册，我们都会向购买邮箱发送通知；如果不是你本人，可以直接通过该邮件中的链接更换密钥。

想换到另一台 Mac 怎么办？

在当前使用的 Mac 上，点按“设置 › 许可证”中的“停用”释放名额，然后在新 Mac 上用同一个密钥注册即可。如果旧 Mac 已无法使用、没能停用，在新 Mac 上注册时若名额已满，应用会显示已注册的 Mac 列表（型号、注册日期、最后使用日期）；停用不再使用的 Mac 后，此 Mac 会立即完成注册（停用其他 Mac 每 30 天最多 3 次）。一个密钥最多可同时用于 2 台 Mac。

更新期结束后就不能使用应用了吗？

不会。一次购买即可一直使用。更新期内发布的版本，在更新期结束后仍可照常使用。只有更新期结束后发布的版本，才需要续订更新（每年 US$15）才能安装。续订会自动进行（续订前 7 天通过付款邮箱和应用内提示通知您），可随时通过 Paddle 付款通知邮件中的管理链接或“设置 › 许可证 › 管理付款…”关闭；更新期结束后再续订的，从该次付款之日起重新计算 1 年。

试用结束后会怎样？

14 天试用无需付款方式即可开始，因此结束后不会自动扣款。如果试用结束时没有许可证密钥，可继续使用描述文件管理（含下载 · 创建 · 设备注册）· 产物检查 · API 密钥管理 · 历史记录（仅查看）；应用构建 · 任务队列 · 上传应用 · 设备安装 · 重新签名 · 库 · IPA 整理 · OTA 分发 · 商店分发在购买后于「设置 › 许可证」中填入密钥即可重新开启。

免费期到什么时候？

到 2026年12月31日 为止。在此之前无需许可证即可使用所有功能。自 2027年1月1日 起，应用构建 · 任务队列 · 上传应用 · 设备安装 · 重新签名 · 库 · IPA 整理 · OTA 分发 · 商店分发需要许可证，描述文件管理 · 产物检查 · API 密钥管理 · 历史记录（仅查看）仍可继续使用。如果你在免费期最后 14 天内首次启动应用，试用会持续到首次启动后 14 天。应用会在结束前 7 天和最后一天提醒你。

如何申请退款？

首次购买和更新续订均可在付款后 14 天内全额退款。请将付款邮箱和订单号（见 Paddle 收据）发送至 support@shouarchive.beakbig.com，销售者会立即向 Paddle 申请退款——这是最快的方法。也可以通过 Paddle 收据邮件中的链接或在 paddle.net 直接申请。应用的“设置 › 许可证 › 如何取消…”中也有相同说明。详细标准见退款政策。

我想删除我的个人信息

在删除个人信息页面输入付款时使用的邮箱，我们会发送确认邮件。在邮件链接中点按“删除”后，该邮箱的全部许可证将被终止，已注册的 Mac 被解除，购买邮箱 · 密钥 · 发送记录也会被删除。此操作无法撤销，也无法再重新获取密钥。支付记录（交易 id · 类型 · 时间）依法保存 5 年；Paddle 持有的支付信息请另行向 Paddle 申请。详情见隐私政策第 11 项。

常规

如何更改显示语言？

在工具栏的地球图标菜单中选择语言，然后点按「立即重新启动」，应用就会以该语言重新打开。语言需要重新启动应用才会生效，正在进行的工作会被保留。支持 한국어 · English · 日本語 · 简体中文 · 繁體中文 · Español。

主题和文本大小？

在工具栏的主题菜单中选择颜色主题（Black & White · ShouArchive）以及浅色 · 深色 · 系统设置。文本大小可通过「显示」菜单的「放大文本 ⌘+ · 缩小文本 ⌘- · 默认大小 ⌘0」，或在设置（⌘,）›「界面」中于 85 % ~ 150 % 之间调整。

系统要求

macOS 15 Sequoia 或更高版本。同时支持 Apple Silicon 和 Intel Mac。下载与创建描述文件、注册设备需要 App Store Connect API 密钥；许可证验证 · 检查更新 · 上传应用 · 商店分发需要网络连接。产物检查和查看已安装的描述文件无需联网即可使用。
