快速上手

描述文件是从哪里读取的？

应用会直接读取 Xcode 存放描述文件的文件夹，无需另外授权或设置。

  • ~/Library/Developer/Xcode/UserData/Provisioning Profiles — Xcode 16 及更高版本
  • ~/Library/MobileDevice/Provisioning Profiles — 较早的 Xcode 版本

存放在其他位置的 .mobileprovision 文件，可以拖入窗口，或通过「从文件添加…」打开查看。

支持哪些文件类型？
  • 产物检查：.ipa（iOS 标签页）、.apk · .aab（Android 标签页）
  • 描述文件：.mobileprovision
  • API 密钥：从 App Store Connect 下载的 .p8

将文件拖到窗口上，或使用「选择文件…」（⌘O）打开。

描述文件 · App Store Connect API

如何创建 App Store Connect API 密钥？
  1. 前往 App Store Connect › 用户和访问 › 集成 › App Store Connect API。
  2. 生成一个团队密钥（Team key）。读取和创建描述文件与设备通常需要管理（Admin）角色。
  3. 在应用底部菜单的「API 密钥」标签页（或设置（⌘,）›「API 密钥」）中点按「新密钥」，登记 Issuer ID、Key ID 和下载的 .p8 文件。选择 AuthKey_XXXXXXXX.p8 文件时会自动填入 Key ID，保存时会从 Apple 读取团队（读取不到时会提示你自行选择）。粘贴时夹带的空格和换行会被自动去除。

Apple 只允许下载一次 .p8 文件，请妥善保管。应用不会使用 Apple ID 或双重认证。

API 密钥保存在哪里？会发送到哪里？

.p8 文件留在你选择的位置，应用只记住该文件的位置（安全作用域书签）。发送给 Apple 的请求令牌在 Mac 上签名，密钥本身除了 Apple 的 App Store Connect API（api.appstoreconnect.apple.com）之外不会发送到任何地方。在应用中删除密钥不会删除 .p8 文件。

「即将过期」和 D-N 徽章的标准是什么？

距离到期30 天以内的会归为「即将过期」，并以 D-N（橙色）徽章显示剩余天数。已经过期的则为「到期」（红色）。「新增」表示最近创建的描述文件；「重复」表示同一团队、同一 App ID、同一类型的描述文件有 2 个或以上。

「证书」卡片中显示什么？

显示这台 Mac 钥匙串中的代码签名证书，包括已过期的证书。描述文件中内嵌的证书可在详情视图和比较视图中查看（可复制 SHA-1 · SHA-256）。

设备注册上限是多少？

Apple 开发者账户在每个会员年度内，每种设备类型（iPhone · iPad · Mac……）最多可注册 100 台。设为停用的设备在会员资格续期之前仍会占用名额。「描述文件」›「下载描述文件」中「设备」标签页的上方会显示各类型的用量（例如 iPhone 3 / 100）。

产物检查

检查会修改文件或把它上传到某处吗？

不会。文件只会被读取。原文件不会被修改，不会在旁边写入结果文件，也不会发送到任何服务器。检查结果只显示在应用窗口中。

我不明白项目名称是什么意思。

点击带虚线下划线的项目名称（权限 · 设备功能 · 清单设置 · 证书指纹 · Entitlements 等），会以弹出框显示是什么 · 详情 · 注意事项说明。16 KB 卡片请点击标题旁的 ⓘ。

16 KB 页面大小检查看的是什么？

从 Android 15 开始，部分设备使用 16 KB 内存页，Google Play 要求原生库对此提供支持。应用会检查 64 位（arm64-v8a · x86_64）.so 文件的 ELF LOAD 对齐，以及 APK 中以未压缩方式存储的 .so 的 16 KB 边界，并列出不支持的库。

价格 · 许可证

多少钱？包含哪些内容？

首次购买为 US$29（不含税），包含许可证和 1 年更新。一个许可证密钥可用于 2 台 Mac。包含描述文件管理 · API 密钥 · 产物检查 · 构建 · 上传应用 · 设备安装 · 依赖检查 · OTA 安装包 · 商店分发全部功能。试用期间 · 试用结束后 · 购买后分别能用哪些功能，整理在价格页面的表格中。

什么时候推出？

价格已经确定——首次购买 US$29（含 1 年更新），之后的更新为每年 US$15（不含税）。推出日期尚未确定。确定之后我们会写在价格页面和下载页面上。如有疑问，请发送邮件至 support@beakbig.com。

想换到另一台 Mac 怎么办？

在当前使用的 Mac 上，点按「设置 › 许可证」中的「解除」释放名额，然后在新 Mac 上输入同一个密钥即可。一个密钥最多可同时用于 2 台 Mac。

更新期结束后就不能使用应用了吗？

不会。一次购买即可一直使用。更新期内发布的版本，在更新期结束后仍可照常使用。只有更新期结束后发布的版本，才需要续订更新（每年 US$15）才能安装。续订会自动进行，可随时关闭；更新期结束后再续订的，从该次付款之日起重新计算 1 年。

试用结束后会怎样？

14 天试用无需付款方式即可开始，因此结束后不会自动扣款。如果试用结束时没有许可证密钥，只能继续使用描述文件管理和产物检查；构建 · 上传 · 设备安装 · 依赖检查 · OTA · 商店分发在购买后于「设置 › 许可证」中填入密钥即可重新开启。

常规

如何更改显示语言？

在工具栏的地球图标菜单中选择语言，然后点按「立即重新启动」，应用就会以该语言重新打开。语言需要重新启动应用才会生效，正在进行的工作会被保留。支持 한국어 · English · 日本語 · 简体中文 · 繁體中文 · Español。

主题和文本大小？

在工具栏的主题菜单中选择颜色主题（Black & White · ShouArchive）以及浅色 · 深色 · 系统设置。文本大小可通过「显示」菜单的「放大文本 ⌘+ · 缩小文本 ⌘- · 默认大小 ⌘0」，或在设置（⌘,）›「界面」中于 85 % ~ 150 % 之间调整。

系统要求

macOS 15 Sequoia 或更高版本。同时支持 Apple Silicon 和 Intel Mac。下载与创建描述文件、注册设备需要 App Store Connect API 密钥；许可证验证 · 检查更新 · 上传应用 · 商店分发需要网络连接。产物检查和查看已安装的描述文件无需联网即可使用。
