更新紀錄

ShouArchive 各版本的更新紀錄

1.0.6 — 2026年10月31日

新增

  • App 建置 — 未安裝 Xcode 時，開啟 iOS 的 App 建置畫面會在視窗中央顯示提示。「前往 App Store」會開啟 App Store 中的 Xcode 頁面，「關閉」會回到上一個畫面
  • App 建置 — 缺少 Android SDK 或 JDK 時也會顯示同樣的提示。「前往下載頁面」會開啟 Android Studio 下載頁面；若已安裝 Android Studio，按鈕會變為「開啟 Android Studio」
  • App 建置 — 建置畫面上方的提示與失敗的工作中也新增了「從 App Store 取得 Xcode」「取得 Android Studio」按鈕。安裝後回到 ShouArchive，提示就會消失

變更

  • API 金鑰 — 用「匯出備份」儲存後，會在 Finder 中選取並顯示儲存的檔案

修正

  • App 建置 — 未安裝 Xcode 時，iOS 建置、上傳、安裝到裝置等操作會直接顯示 Apple 的英文錯誤，現在改為「此操作需要 Xcode」的提示，也不再跳出 macOS 的開發者工具安裝視窗
  • App 建置 — 修正已安裝 Xcode 但 xcode-select 指向 Command Line Tools 時 iOS 作業失敗的問題。現在會自動找到並使用已安裝的 Xcode

1.0.5 — 2026年10月31日

變更

  • API 金鑰 — iOS 金鑰的 .p8 內容現在儲存在 macOS 鑰匙串中。刪除或移動原 .p8 檔案後仍可繼續使用；已加入的金鑰只要原檔案還在，啟動時也會移入鑰匙串
  • API 金鑰 — iOS 金鑰也新增了「匯出備份」，可將鑰匙串中儲存的 .p8 存成 AuthKey_<Key ID>.p8 檔案
  • 授權 — 開啟這台 Mac 正在使用的金鑰的連結時，只會提示「此授權已在這台 Mac 上註冊」
  • 授權 — 換成另一個授權的金鑰時，會釋出這台 Mac 在先前授權中的席位
  • 授權 — 已撤銷的授權在 設定 › 授權 中顯示為購買前的樣子（只保留狀態、原因與金鑰）

修正

  • 授權 — 透過連結註冊金鑰失敗時，錯誤不再與警告重複顯示兩次
  • API 金鑰 — 修正「匯出備份」因未建立新資料夾而無法儲存的問題
  • 確認視窗 — 修正部分確認視窗（金鑰備份、刪除金鑰、建立封閉測試軌道）出現兩個「取消」按鈕的問題

1.0.4 — 2026年10月30日

修正

  • 視窗大小 — 用底部分頁列或子選單切換畫面時，若視窗自行縱向變長，會恢復到之前的高度
  • macOS 26 — 工具列加上了背景，視窗標題不再壓在左欄的分隔線上
  • 描述檔 — 修正了英文介面中憑證到期日前少了空格的問題

1.0.3 — 2026年10月29日

變更

  • 資訊 — 移到左上角 iOS / Android 旁邊（不再位於底部分頁列），可在其中選擇 iOS、Android 或 ShouArchive
  • 更新記錄 — 資訊 › ShouArchive 列出每個版本的變更；有新版本時顯示「新版本」與「檢查更新…」

1.0.2 — 2026年10月29日

變更

  • 資訊 — 「查看原文」會開啟 App 語言的譯文頁面（沒有譯文時開啟英文原文）
  • API 金鑰 — 儲存或刪除金鑰的結果會在畫面上方短暫顯示

1.0.1 — 2026年10月29日

新增

  • 資訊 — 彙整 Apple 與 Google 審查與政策資訊的新分頁（位於底部分頁列最右側，附未讀標記）。可在 設定 › 一般 中關閉自動取得
