描述檔

描述檔：從到期日到裝置註冊

一眼看遍 Xcode 已安裝的所有描述檔。加入 App Store Connect API 金鑰後，不必離開 App 就能下載、建立與續期描述檔。

已安裝的描述檔

  • 每一列都有 D-N 到期標記 — 30 天內轉為橘色，過期後轉為紅色
  • 篩選：全部 · 新增 · 重複 / 有效 · 即將過期 · 到期，也可依團隊與憑證類型（Developer · Distribution · Ad Hoc · Enterprise）篩選
  • 詳細資料：裝置 UDID、內嵌憑證（SHA-1 · SHA-256）與 Entitlements，皆可一鍵複製
  • 進入列表後會在背景自動讀取詳細資料，除名稱、Bundle ID、UUID 之外，也能直接用裝置 UDID 搜尋
  • 選取兩個描述檔，在上方的比較列並排比較，列出不同的裝置、憑證與 Entitlements
  • 拖入 .mobileprovision 檔案即可新增；多選後可一併刪除

App Store Connect API

  • 在「API 金鑰」分頁依團隊儲存、管理多把金鑰 — 儲存時自動讀取團隊
  • 取得團隊的描述檔，只安裝缺少的項目
  • 列出已註冊的裝置並註冊新裝置，同時顯示各類型的額度（例如 iPhone 3 / 100）
  • 建立描述檔：類型、平台、Bundle ID、憑證、裝置
  • 裝置有變動或即將到期時，重新建立或續期

只會用到 Issuer ID、Key ID 與 .p8 檔案。金鑰留在您的 Mac 上，請求權杖皆於本機簽署。

產物檢查

上傳前先打開 IPA、APK 或 AAB

拖入檔案，當場解析 — 不需要外部工具。從商店資訊到簽署、權限與安全設定，每個項目都附有淺白易懂的說明。

商店資訊

可直接從產物讀出的產品頁面資訊。

  • 圖示、名稱、提供者、大小、支援的語言
  • iOS：類別、相容性、App Tracking Transparency 提示、隱私權資訊清單摘要
  • Android：下載大小、所需 Android 版本、權限數量、App 內購買、廣告 ID、支援的裝置

iOS 簽署與權限

  • 簽署、描述檔與 Entitlements
  • 權限用途說明（…UsageDescription）— 留空時會提出警告
  • 框架、應用程式擴充功能與 Entitlements 清單完整顯示，絕不截斷

Android 簽署、安全與 16 KB

  • 憑證指紋 SHA-256 · SHA-1 · MD5，以及 Kakao 與 Facebook 用的金鑰雜湊
  • 權限分類與裝置功能
  • 資訊清單安全設定：allowBackup、明文 HTTP、exported 元件、深層連結
  • 原生函式庫的 16 KB 頁面大小對齊檢查
  • 建置、配置與大小明細（DEX、資源、各 ABI 的原生函式庫）

唯讀。絕不修改檔案，不會在檔案旁寫入任何內容，也不會上傳到任何地方。
