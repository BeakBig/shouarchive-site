ShouArchive

描述檔、產物檢查與 OTA 安裝檔案 — 出貨前的最後幾道確認，集中在一款 App。

打開 IPA、APK 或 AAB，即可看到商店會顯示的資訊、簽署方式與所要求的權限。連同到期日一起，把描述檔（provisioning profile）整理得井然有序。為測試版本產生 OTA 安裝頁面。您的檔案永遠不會離開您的 Mac。

在 Mac App Store 下載 看看它能做什麼

macOS 15 Sequoia 或以上版本 · Apple Silicon 與 Intel

描述檔

描述檔：從到期日到裝置註冊

一眼看遍 Xcode 已安裝的所有描述檔。加入 App Store Connect API 金鑰後，不必離開 App 就能下載、建立與續期描述檔。

已安裝的描述檔

  • 每一列都有 D-N 到期標記 — 30 天內轉為橘色，過期後轉為紅色
  • 篩選：全部 · 新增 · 重複 / 有效 · 即將過期 · 到期
  • 詳細資料：裝置 UDID、內嵌憑證（SHA-1 · SHA-256）與 Entitlements，皆可一鍵複製
  • 比較兩個描述檔，並排列出不同的裝置、憑證與 Entitlements
  • 拖入 .mobileprovision 檔案即可新增；多選後可一併刪除

App Store Connect API

  • 取得團隊的描述檔，只安裝缺少的項目
  • 列出已註冊的裝置並註冊新裝置，同時顯示各類型的額度（例如 iPhone 3 / 100）
  • 建立描述檔：類型、平台、Bundle ID、憑證、裝置
  • 裝置有變動或即將到期時，重新建立或續期

只會用到 Issuer ID、Key ID 與 .p8 檔案。金鑰留在您的 Mac 上，請求權杖皆於本機簽署。

記錄

  • 下載、建立、重新建立、裝置註冊、新增與刪除，依日期分組
  • 可依名稱、Bundle ID、UUID 或 UDID 搜尋
  • 想追查什麼時候改了什麼時，特別方便

產物檢查

上傳前先打開 IPA、APK 或 AAB

拖入檔案，當場解析 — 不需要外部工具。從商店資訊到簽署、權限與安全設定，每個項目都附有淺白易懂的說明。

商店資訊

可直接從產物讀出的產品頁面資訊。

  • 圖示、名稱、提供者、大小、支援的語言
  • iOS：類別、相容性、App Tracking Transparency 提示、隱私權資訊清單摘要
  • Android：下載大小、所需 Android 版本、權限數量、App 內購買、廣告 ID、支援的裝置

iOS 簽署與權限

  • 簽署、描述檔與 Entitlements
  • 權限用途說明（…UsageDescription）— 留空時會提出警告
  • 框架、應用程式擴充功能與 Entitlements 清單完整顯示，絕不截斷

Android 簽署、安全與 16 KB

  • 憑證指紋 SHA-256 · SHA-1 · MD5，以及 Kakao 與 Facebook 用的金鑰雜湊
  • 權限分類與裝置功能
  • 資訊清單安全設定：allowBackup、明文 HTTP、exported 元件、深層連結
  • 原生函式庫的 16 KB 頁面大小對齊檢查
  • 建置、配置與大小明細（DEX、資源、各 ABI 的原生函式庫）

唯讀。絕不修改檔案，不會在檔案旁寫入任何內容，也不會上傳到任何地方。

OTA 發布

一個連結就能安裝測試版本

把現有的 IPA 或 APK 變成安裝頁面與 QR Code。將檔案上傳到您自己的 https 伺服器，就大功告成。

iOS — Ad Hoc · Enterprise

  • manifest.plist、install.html，以及 itms-services:// 安裝連結的 QR Code
  • Bundle ID、版本、組建編號與應用程式名稱皆從 IPA 自動填入
  • 您輸入的發行說明會直接放進安裝頁面

Android — APK

  • install.html，內含圖示、版本、SHA-256、安裝說明與更新內容
  • 指向安裝頁面的 QR Code
  • 套件名稱、版本、應用程式名稱與圖示皆從 APK 自動填入

由您自行託管

  • 選擇輸出資料夾，檔案就會寫入該處
  • App 不會上傳任何東西 — 請把檔案放到團隊的 https 伺服器
  • iOS 需要 https，且連結必須在裝置上的 Safari 開啟
