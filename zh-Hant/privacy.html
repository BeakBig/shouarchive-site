隱私權政策

ShouArchive for macOS · 生效日期 2026年9月22日 · 開發者：BeakBig

簡而言之：ShouArchive 不收集任何個人資料。沒有分析工具、沒有追蹤、沒有廣告、不需要帳號，您檢查的檔案也只在您的 Mac 上讀取。只有在您登錄自己的 App Store Connect API 金鑰、由 App 代您與 Apple 通訊時，才會使用網路。

1. 我們收集的資料

無。本 App 不會：

  • 收集使用統計或當機報告等分析資料；
  • 追蹤您或您的裝置，或顯示廣告；
  • 要求帳號或登入；
  • 包含任何會透過網路通訊的第三方 SDK。

2. 您開啟的檔案

產物檢查、OTA 發布與描述檔管理所處理的檔案（IPA、APK、AAB、.mobileprovision）只在您的 Mac 上讀取。其內容及由此得出的任何資訊（Bundle ID、簽署憑證、權限清單等）只會顯示在 App 視窗中，絕不會傳送到任何地方。檢查絕不會修改原始檔案。

OTA 檔案（manifest.plist、install.html、QR 圖片）只會寫入您選擇的資料夾。App 不會將它們上傳到任何伺服器。

3. 網路使用

本 App 只在一種情況下使用網路：當您登錄自己的 App Store Connect API 金鑰（Issuer ID、Key ID 與 .p8 檔案）並使用需要它的功能時，App 會連線到 Apple 的 App Store Connect API（api.appstoreconnect.apple.com）。

列出並下載描述檔由 App 簽署的驗證權杖
建立、重新建立或續期描述檔權杖，以及您選擇的描述檔類型、Bundle ID、憑證與裝置

  • .p8 私密金鑰留在您的 Mac 上。App 只儲存該檔案的參照（macOS 安全範圍書籤），並在本機簽署請求權杖。金鑰本身絕不會傳送到任何地方，包括 Apple。
  • Apple 對這些請求的處理方式，受 Apple Developer Program 相關協議與 Apple 隱私權政策規範。
  • 如果您從未登錄 API 金鑰，App 完全不會進行任何網路連線。

4. 儲存在您 Mac 上的資料

  • App 設定（主題、語言、文字大小、OTA URL 設定、API 金鑰資訊等）儲存在 macOS 提供給 App 的沙箱容器中。
  • 描述檔資料夾與 .p8 檔案的存取權，會以您在開啟面板中授予的安全範圍書籤記住。您隨時可以在 App 中移除。
  • 描述檔的活動記錄（下載、建立、裝置註冊等）保存在本機，可用「清除記錄」清除。
  • 刪除 App 會一併移除其容器與這些資料。您自行放置的檔案（例如 .p8 檔案）絕不會被 App 刪除。

5. 第三方函式庫

本 App 內建開源函式庫 Lottie，用於播放載入動畫。它僅用於顯示，不會存取網路或收集資料。沒有其他第三方 SDK。

6. 分享與販售

既然沒有收集任何資料，也就不會與任何人分享或販售。第 3 節所述與 Apple 的通訊，是在您的要求下，使用您自己的帳號與金鑰進行的。

7. 兒童

ShouArchive 是為軟體開發者設計的工具，並非以兒童為對象。它不會向任何人收集個人資訊。

8. 變更

若本政策有所變更，新版本將連同更新後的生效日期一併公布在本頁面。若 App 處理資料的方式確實有所改變，App 的發行說明中也會一併說明。

9. 聯絡方式
