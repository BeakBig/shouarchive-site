支援

使用 ShouArchive 時遇到卡關的地方，請告訴我們。下方的常見問題中可能已經有答案。

聯絡方式 support@shouarchive.beakbig.com 寄出後會立即收到自動確認信，負責人確認後會在一天內回覆。回報問題的訣竅請見頁面底部。

開始使用

描述檔是從哪裡讀取的？

App 會直接讀取 Xcode 存放描述檔（provisioning profile）的資料夾。不需要另外允許或設定任何東西。

  • ~/Library/Developer/Xcode/UserData/Provisioning Profiles — Xcode 16 或以上版本
  • ~/Library/MobileDevice/Provisioning Profiles — 較舊的 Xcode 版本

存放在其他位置的 .mobileprovision 檔案，可以拖入視窗或用「從檔案新增…」開啟。

支援哪些檔案類型？
  • 產物檢查：.ipa（iOS 分頁）、.apk · .aab（Android 分頁）
  • 描述檔：.mobileprovision
  • API 金鑰：從 App Store Connect 下載的 .p8

將檔案拖到視窗上，或使用「選擇檔案…」（⌘O）開啟。

描述檔與 App Store Connect API

如何建立 App Store Connect API 金鑰？
  1. 前往 App Store Connect › 使用者和存取權限 › 整合 › App Store Connect API。
  2. 產生一組團隊金鑰（Team key）。讀取與建立描述檔和裝置通常需要 Admin 角色。
  3. 在 App 底部選單的「API 金鑰」分頁（或「設定」（⌘,）›「API 金鑰」）按「新金鑰」，輸入 Issuer ID、Key ID 與下載的 .p8 檔案。選擇 AuthKey_XXXXXXXX.p8 檔案時會自動填入 Key ID，儲存時會從 Apple 讀取團隊（讀取不到時會提示您自行選擇）。貼上時夾帶的空格與換行會自動移除。

Apple 只允許下載 .p8 檔案一次，請妥善保管。App 不會使用您的 Apple ID 或雙重認證。

API 金鑰存放在哪裡？會傳送到哪裡？

.p8 檔案留在您選擇的位置，App 只記住該檔案的位置（安全範圍書籤）。傳給 Apple 的請求權杖在您的 Mac 上簽署，金鑰本身除了 Apple 的 App Store Connect API（api.appstoreconnect.apple.com）之外，不會傳送到任何地方。在 App 中刪除金鑰並不會刪除 .p8 檔案。

「即將過期」和 D-N 標記是什麼意思？

30 天內到期的描述檔屬於「即將過期」，會以橘色的 D-N 標記顯示剩餘天數。已超過到期日的則為「到期」（紅色）。「新增」表示最近才建立的描述檔；「重複」則表示團隊、App ID 與類型都相同的描述檔有兩個以上。

「憑證」卡片會顯示什麼？

會顯示這台 Mac 鑰匙圈中的程式碼簽署憑證，連已過期的也一併列出。描述檔內嵌的憑證可在詳細資料與比較畫面中查看（可複製 SHA-1 · SHA-256）。

我可以註冊多少台裝置？

Apple 開發者帳號在每個會員年度內，每種裝置類型（iPhone · iPad · Mac……）最多可註冊 100 台。停用的裝置在會員資格續約前仍會占用名額。「描述檔」›「下載描述檔」中的「裝置」分頁上方會顯示各類型的使用量（例如 iPhone 3 / 100）。

產物檢查

檢查檔案會修改或上傳它嗎？

不會。檔案只會被讀取：絕不修改原始檔案、不會在旁邊寫入結果檔案，也不會傳送到任何伺服器。檢查結果只顯示在 App 視窗中。

我看不懂某個項目的意思。

帶有點狀底線的項目名稱（權限、裝置功能、資訊清單設定、憑證指紋、Entitlements 等）點一下就會彈出說明，分為是什麼 · 詳細說明 · 注意事項三部分。16 KB 卡片請按標題旁的 ⓘ。

16 KB 頁面大小檢查會看什麼？

從 Android 15 開始，部分裝置採用 16 KB 記憶體分頁，Google Play 也要求原生函式庫必須支援。App 會檢查 64 位元（arm64-v8a · x86_64）.so 檔案的 ELF LOAD 對齊，以及 APK 中以未壓縮方式存放的 .so 的 16 KB 邊界，並列出不支援的函式庫。

OTA 發佈

ShouArchive 會代管 OTA 安裝檔案嗎?

不會。ShouArchive 在 IPA · APK 旁邊的 <名稱>_OTA 資料夾中產生安裝頁面(install.html)、manifest.plist 和 QR 碼,只負責產生這些檔案,不代管檔案,也不提供下載連結。請把整個資料夾上傳到您自己營運的 HTTPS 伺服器(公司網站伺服器、雲端儲存的靜態代管等),並讓位置與在 App 中輸入的 IPA 網址一致。iOS 只會從 HTTPS 網址開始安裝。

價格 · 授權

多少錢？包含哪些內容？

首次購買為 US$29（未稅），包含授權與 1 年更新。一組授權金鑰可用於 2 台 Mac。描述檔管理 · API 金鑰 · 產物檢查 · 歷史記錄 · App 建置 · 工作佇列 · App 上傳 · 裝置安裝 · 重新簽署 · 資源庫 · IPA 整理 · OTA 發佈 · 商店發佈全部包含在內。試用期間、試用結束後與購買後可使用的功能，已整理在價格頁面的表格中。

什麼時候推出？

價格已經確定 — 首次購買 US$29（含 1 年更新），之後的更新為每年 US$15（未稅）。推出日期還沒確定。確定之後我們會寫在價格頁面和下載頁面上。現在已可從下載頁面下載，試用 14 天。有任何疑問，請寄信至 support@shouarchive.beakbig.com。

如何註冊授權金鑰？

付款完成後，您會在付款完成頁面和郵件中收到金鑰。在已安裝 ShouArchive 的 Mac 上，按付款完成頁面上的「在 ShouArchive 中開啟」或郵件中的「在 App 中直接註冊」連結，App 會詢問是否在此 Mac 上註冊，按「註冊」即可完成。如果連結無法開啟 App，請在「設定 › 授權 › 輸入金鑰…」中輸入付款時的電子郵件和金鑰。如果是在 App 內付款，也可以在那台 Mac 上按「自動檢查」。僅付款並不會註冊 Mac，如果是為另一台 Mac 購買，請在那台 Mac 上註冊。

授權金鑰遺失了怎麼辦？

在重新取得金鑰頁面輸入付款時使用的電子郵件，我們會將同一組金鑰重新寄送到該地址。也可以在 App 的「設定 › 授權 › 重新取得金鑰…」中申請。金鑰只會寄送到購買時使用的電子郵件地址。如果付款時電子郵件輸入錯誤，請將付款日期和信用卡帳單上顯示的內容寄至 support@shouarchive.beakbig.com。

我的授權金鑰可能已被他人知道

在更換金鑰頁面輸入付款時使用的電子郵件，我們會寄送確認連結（也可以在 App 的「設定 › 授權 › 更換金鑰…」中申請）。開啟連結並按「更換金鑰」後，新金鑰會寄到購買電子郵件，舊金鑰將無法使用，所有已註冊的 Mac 都會被停用。請用新金鑰重新註冊要繼續使用的 Mac。從第二台 Mac 起，每當有新的 Mac 註冊，我們都會寄通知到購買電子郵件；如果不是您本人，可以直接透過該郵件中的連結更換金鑰。

想換到另一台 Mac 怎麼辦？

在目前使用的 Mac 上，於「設定 › 授權」按「停用」釋出名額，再到新的 Mac 用同一組金鑰註冊即可。如果舊 Mac 已無法使用、沒能停用，在新 Mac 上註冊時若名額已滿，App 會顯示已註冊的 Mac 列表（機型、註冊日期、最後使用日期）；停用不再使用的 Mac 後，此 Mac 會立即完成註冊（停用其他 Mac 每 30 天最多 3 次）。一組金鑰最多可同時用於 2 台 Mac。

更新期間結束後就不能使用 App 了嗎？

不會。買一次就能一直使用。更新期間內推出的版本，在期間結束後也能照常使用。只有期間結束後推出的版本，需要續訂更新（每年 US$15）才能安裝。續訂會自動進行（續訂前 7 天會透過付款電子郵件與 App 通知），也可以隨時透過 Paddle 付款通知郵件中的管理連結或「設定 › 授權 › 管理付款…」關閉；若在期間結束後才重新續訂，會從該次付款日起重新開始 1 年。

試用結束後會怎樣？

14 天試用不需付款方式即可開始，因此結束後也不會自動扣款。若試用結束時沒有授權金鑰，描述檔管理（含下載 · 建立 · 裝置註冊）· 產物檢查 · API 金鑰管理 · 歷史記錄（僅檢視）仍可繼續使用；App 建置 · 工作佇列 · App 上傳 · 裝置安裝 · 重新簽署 · 資源庫 · IPA 整理 · OTA 發佈 · 商店發佈，在購買並將金鑰輸入到「設定」›「授權」後會重新開放。

如何申請退款？

首次購買與更新續訂，皆可在付款後 14 天內全額退款。請將付款時的電子郵件地址與訂單編號（記載於 Paddle 收據上）寄至 support@shouarchive.beakbig.com，銷售者會直接向 Paddle 申請退款 — 這是最快的方式。也可以透過 Paddle 收據郵件中的連結或 paddle.net 直接申請。App 的「設定 › 授權 › 如何解約…」中也有相同的說明。詳細標準請見退款政策。

我想刪除我的個人資料

在個人資料刪除頁面輸入付款時使用的電子郵件，我們會寄送確認郵件。在郵件的連結中按「刪除」後，該電子郵件地址的所有授權都會被撤銷，已註冊的 Mac 會被解除，購買電子郵件地址 · 金鑰 · 寄送記錄也會被刪除。此操作無法復原，也無法再重新取得金鑰。付款記錄（交易 id · 類型 · 時間）依法保存 5 年；Paddle 持有的付款資訊請另行向 Paddle 申請。詳細內容請見隱私權政策第 11 項。

一般

如何變更顯示語言？

在工具列的地球儀選單中選擇語言，再按「立即重新啟動」，App 就會以該語言重新開啟。語言需要重新啟動 App 才會套用，您正在進行的工作會保留。支援 한국어 · English · 日本語 · 简体中文 · 繁體中文 · Español。

主題與文字大小？

在工具列的主題選單中選擇色彩主題（Black & White · ShouArchive）以及淺色 · 深色 · 系統設定。文字大小可透過「顯示方式」選單（放大文字 ⌘+ · 縮小文字 ⌘- · 預設大小 ⌘0）或「設定」（⌘,）›「畫面」，在 85 % 到 150 % 之間調整。

系統需求

macOS 15 Sequoia 或以上版本。支援 Apple Silicon 與 Intel Mac。下載與建立描述檔、註冊裝置需要 App Store Connect API 金鑰；授權驗證、檢查更新、App 上傳與商店發佈需要網路連線。產物檢查與檢視已安裝的描述檔不需要網路也能運作。
