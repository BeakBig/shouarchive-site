支援

使用 ShouArchive 時遇到卡關的地方，請告訴我們。下方的常見問題中可能已經有答案。

聯絡方式 support@beakbig.com 通常會在幾天內回覆。回報問題的訣竅請見頁面底部。

開始使用

描述檔是從哪裡讀取的？

App 會直接讀取 Xcode 存放描述檔（provisioning profile）的資料夾。不需要另外允許或設定任何東西。

  • ~/Library/Developer/Xcode/UserData/Provisioning Profiles — Xcode 16 或以上版本
  • ~/Library/MobileDevice/Provisioning Profiles — 較舊的 Xcode 版本

存放在其他位置的 .mobileprovision 檔案，可以拖入視窗或用「從檔案新增…」開啟。

支援哪些檔案類型？
  • 產物檢查：.ipa（iOS 分頁）、.apk · .aab（Android 分頁）
  • 描述檔：.mobileprovision
  • API 金鑰：從 App Store Connect 下載的 .p8

將檔案拖到視窗上，或使用「選擇檔案…」（⌘O）開啟。

描述檔與 App Store Connect API

如何建立 App Store Connect API 金鑰？
  1. 前往 App Store Connect › 使用者和存取權限 › 整合 › App Store Connect API。
  2. 產生一組團隊金鑰（Team key）。讀取與建立描述檔和裝置通常需要 Admin 角色。
  3. 在 App 底部選單的「API 金鑰」分頁（或「設定」（⌘,）›「API 金鑰」）按「新金鑰」，輸入 Issuer ID、Key ID 與下載的 .p8 檔案。選擇 AuthKey_XXXXXXXX.p8 檔案時會自動填入 Key ID，儲存時會從 Apple 讀取團隊（讀取不到時會提示您自行選擇）。貼上時夾帶的空格與換行會自動移除。

Apple 只允許下載 .p8 檔案一次，請妥善保管。App 不會使用您的 Apple ID 或雙重認證。

API 金鑰存放在哪裡？會傳送到哪裡？

.p8 檔案留在您選擇的位置，App 只記住該檔案的位置（安全範圍書籤）。傳給 Apple 的請求權杖在您的 Mac 上簽署，金鑰本身除了 Apple 的 App Store Connect API（api.appstoreconnect.apple.com）之外，不會傳送到任何地方。在 App 中刪除金鑰並不會刪除 .p8 檔案。

「即將過期」和 D-N 標記是什麼意思？

30 天內到期的描述檔屬於「即將過期」，會以橘色的 D-N 標記顯示剩餘天數。已超過到期日的則為「到期」（紅色）。「新增」表示最近才建立的描述檔；「重複」則表示團隊、App ID 與類型都相同的描述檔有兩個以上。

「憑證」卡片會顯示什麼？

會顯示這台 Mac 鑰匙圈中的程式碼簽署憑證，連已過期的也一併列出。描述檔內嵌的憑證可在詳細資料與比較畫面中查看（可複製 SHA-1 · SHA-256）。

我可以註冊多少台裝置？

Apple 開發者帳號在每個會員年度內，每種裝置類型（iPhone · iPad · Mac……）最多可註冊 100 台。停用的裝置在會員資格續約前仍會占用名額。「描述檔」›「下載描述檔」中的「裝置」分頁上方會顯示各類型的使用量（例如 iPhone 3 / 100）。

產物檢查

檢查檔案會修改或上傳它嗎？

不會。檔案只會被讀取：絕不修改原始檔案、不會在旁邊寫入結果檔案，也不會傳送到任何伺服器。檢查結果只顯示在 App 視窗中。

我看不懂某個項目的意思。

帶有點狀底線的項目名稱（權限、裝置功能、資訊清單設定、憑證指紋、Entitlements 等）點一下就會彈出說明，分為是什麼 · 詳細說明 · 注意事項三部分。16 KB 卡片請按標題旁的 ⓘ。

16 KB 頁面大小檢查會看什麼？

從 Android 15 開始，部分裝置採用 16 KB 記憶體分頁，Google Play 也要求原生函式庫必須支援。App 會檢查 64 位元（arm64-v8a · x86_64）.so 檔案的 ELF LOAD 對齊，以及 APK 中以未壓縮方式存放的 .so 的 16 KB 邊界，並列出不支援的函式庫。

價格 · 授權

多少錢？包含哪些內容？

首次購買為 US$29（未稅），包含授權與 1 年更新。一組授權金鑰可用於 2 台 Mac。描述檔管理 · API 金鑰 · 產物檢查 · 建置 · App 上傳 · 裝置安裝 · 相依性檢查 · OTA 安裝檔 · 商店發佈全部包含在內。試用期間、試用結束後與購買後可使用的功能，已整理在價格頁面的表格中。

什麼時候推出？

價格已經確定 — 首次購買 US$29（含 1 年更新），之後的更新為每年 US$15（未稅）。推出日期還沒確定。確定之後我們會寫在價格頁面和下載頁面上。有任何疑問，請寄信至 support@beakbig.com。

想換到另一台 Mac 怎麼辦？

在目前使用的 Mac 上，於「設定」›「授權」按「解除」釋出名額，再到新的 Mac 輸入同一組金鑰即可。一組金鑰最多可同時用於 2 台 Mac。

更新期間結束後就不能使用 App 了嗎？

不會。買一次就能一直使用。更新期間內推出的版本，在期間結束後也能照常使用。只有期間結束後推出的版本，需要續訂更新（每年 US$15）才能安裝。續訂會自動進行，也可以隨時關閉；若在期間結束後才重新續訂，會從該次付款日起重新開始 1 年。

試用結束後會怎樣？

14 天試用不需付款方式即可開始，因此結束後也不會自動扣款。若試用結束時沒有授權金鑰，只能繼續使用描述檔管理與產物檢查；建置 · 上傳 · 裝置安裝 · 相依性檢查 · OTA · 商店發佈，在購買並將金鑰輸入到「設定」›「授權」後會重新開放。

一般

如何變更顯示語言？

在工具列的地球儀選單中選擇語言，再按「立即重新啟動」，App 就會以該語言重新開啟。語言需要重新啟動 App 才會套用，您正在進行的工作會保留。支援 한국어 · English · 日本語 · 简体中文 · 繁體中文 · Español。

主題與文字大小？

在工具列的主題選單中選擇色彩主題（Black & White · ShouArchive）以及淺色 · 深色 · 系統設定。文字大小可透過「顯示方式」選單（放大文字 ⌘+ · 縮小文字 ⌘- · 預設大小 ⌘0）或「設定」（⌘,）›「畫面」，在 85 % 到 150 % 之間調整。

系統需求

macOS 15 Sequoia 或以上版本。支援 Apple Silicon 與 Intel Mac。下載與建立描述檔、註冊裝置需要 App Store Connect API 金鑰；授權驗證、檢查更新、App 上傳與商店發佈需要網路連線。產物檢查與檢視已安裝的描述檔不需要網路也能運作。
